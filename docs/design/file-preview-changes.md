# 文件预览与变更切换

状态：已实现
适用范围：Web 与 Desktop 共用的右侧文件预览和变更审查。

## 目标与入口

在文件预览中提供「文件 / 变更」切换。普通工作区文件默认显示当前文件，变更
展示当前工作区 Git 未提交变更；从任务变更进入时默认展示该任务记录的差异，并可
切换到当前文件内容。标题和范围必须明确区分「当前工作区变更」与「本次任务变更」，
历史任务不得退回当前 Git 差异。保留已有的完整审查、恢复与外部打开功能。

## 数据与权限

- 任务差异沿用 Turn / Run / Workflow 的 scoped review 及 revision；只呈现授权的路径。
  当前文件预览由服务端重建审查、校验版本和文件身份，使用记录的执行目录；跨目录
  或证据无法确认时明确提示不可用。
- 普通工作区文件沿用 workspace changes；以仓库根目录及可信路径匹配，保持暂存和
  未暂存层的真实含义；同一文件两层均有修改时分别显示。文件列表被截断时，缺席文件不得断言为无修改。
- 通过 capability 打开的资源必须保持 capability 与原始证据范围；不得以裸路径
  退回更宽的读取接口。没有适当差异授权时明确提示不可用。
- Desktop 任意本地文件不猜测工作区归属，也不将本地路径自动交给其他目录的 daemon。
- 文件内容与历史差异分属不同时间：文件页明确为当前内容；历史证据缺失或损坏时
  显示不可用，不能以工作区差异代替。

## 显示与状态

差异使用已有 DiffViewer 和主题语义色，展示文件名、状态、增删行数、上下文和
截断提示。加载、无修改、非 Git 目录、读取失败、二进制、超限和已删除文件都要
有可区分的状态。打开新文件、变更 scope 或快速切换时不得显示旧请求的结果。
切换不修改文件，不隐式执行恢复；操作遵循原有授权与生命周期。

## 验证

覆盖普通文件和任务入口、切换与返回、staged/unstaged、untracked、删除和重命名、
无变更、非 Git、证据不完整、截断、读取失败、快速切换与权限隔离。运行 Web
类型检查、相关行为测试与浏览器交互，使用隔离的真实 Git 仓库验证实际 daemon
变更数据；记录模拟数据与真实服务的区别，检查浏览器错误并截图。关联实现采用
现有 package 测试与 CI，任何新增模块必须遵守 workspace CI contract。
