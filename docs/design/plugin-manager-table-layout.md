# 插件管理表格与详情抽屉

## Status

本文记录当前 external Cua Driver UI 基线。Packaged macOS 和 Windows 后续会按
[Bundled Embedded Cua Driver](cua-driver-bundled-embedded.md) 增加 included、权限、
interactive session、integrity coverage、损坏、版本不兼容和 external override 状态；
该扩展不属于本表格切片。

## Summary

插件管理使用紧凑表格承载多插件扫描和操作，不再把每个插件渲染成可展开卡片。
表格只展示用户需要立即判断的信息，技术信息通过右侧详情抽屉渐进呈现。

## Table Contract

表格固定三列，并使用与自动化页面相同的完整工作区宽度，不设置居中的内容最大宽度：

- `插件`：图标、名称和一行简短描述。
- `状态`：产品状态点和短状态文字。
- `操作`：安装引导、检查、启用/停用、详情。操作列使用固定宽度，列名和按钮组在列内居中。只有安装或启用等当前主操作显示图标加文字；检查、停用、详情等次级操作使用 30px 图标按钮和 tooltip。

插件行高度保持 58–64px。名称列使用剩余空间，状态列和操作列保持稳定宽度，操作列不换行。
表头固定在列表顶部；插件数量超过可用高度后只滚动表格区域，页面标题和刷新按钮不移动。

状态映射：

- `missing`：未安装。
- `detected`：接入中。
- `connected`：待启用。
- `ready`：已启用。
- `unsupported`：不可用。
- blocked、失败 health 或 runtime blocker：需处理。

正常状态使用中性文字和小状态点，只有错误与阻塞使用警告色。表格不显示说明段落、
贡献标签、最近检查、时间戳或“已启用，可使用”。

## Actions

- 未安装：安装引导、详情。
- 接入中：详情；自动连接期间显示局部 busy 状态。
- 待启用：检查、启用、详情。
- 已启用：检查、停用、详情。
- 不可用：详情。
- 其他插件继续根据 daemon actions 暴露安装、检查、启停和包操作。

所有 mutation 结果通过全局 `LingToast` 展示。表格内不创建消息条、成功 badge 或持久反馈卡。

## Detail Drawer

点击详情打开右侧轻抽屉，不展开表格行。抽屉包含：

- 插件名称、状态、来源。
- 插件 ID、版本。
- 本地驱动路径和 MCP 连接状态（存在时）。
- 只有失败时显示明确失败原因。
- 已关联 MCP 时显示 `查看 MCP 连接`。
- bundled 插件可显示包和运行时预览信息，但不使用灰色 MetaRow。

抽屉不显示最近检查、健康时间戳、最新事件、常规 trust 长说明或贡献 token。顶部全局
`MCP 设置` 从插件页移除，MCP 入口只在相关插件详情中出现。

## Scroll And Layout

- 插件页本身不承担多插件滚动。
- 表格主体使用视口约束高度、`overflow-y: auto`、stable scrollbar gutter。
- 滚动条宽 6px，默认透明，hover/focus-within 时显示。
- 表格滚动、滚动条显示和打开抽屉都不能改变列宽或页面横向位置。
- 验收范围为 1280、1440、1920 桌面宽度，不包含移动端。

## Non-goals

- 不增加搜索、分页、排序、多选或虚拟列表。
- 不改变插件 API、状态机、MCP 接入或安装策略。
- 不合并 Cua Driver 安装引导抽屉与插件详情抽屉。
- 不把插件详情改成独立页面。

## Acceptance Criteria

- 多插件时顶部工具栏和表头固定，只有表格主体滚动。
- 检查、启停和详情在同一行右侧，描述补充插件用途，状态与操作列标题和内容对齐。
- 详情只通过右侧抽屉查看，表格行高不变化。
- 页面不出现行内诊断折叠、最近检查、灰色字段条或顶部 MCP 设置。
- 所有操作提示只使用全局 toast。
