# Ling UI 2.0 实施总计划

## Delivery Rules

- 每个切片先更新设计状态，再改代码，再补证据。
- 每个 PR 只迁移一个基础能力或一组紧密相关页面。
- 不在 UI 迁移中修改 API、状态机、数据库或导航 IA。
- 发现能力缺口时标记 `blocked`，另开业务设计，不伪造前端行为。
- 当前 Media Production 未提交改动必须原样保留。

## Slice 0: Documentation And Inventory

- 完成本目录所有设计文档。
- 登记全部 View、Settings、Overlay、共享组件、CSS 和 E2E。
- 建立当前页面截图路径和状态看板。
- 建立独立 Theme Pack 产品模型、Schema、导入安全和迁移矩阵。
- 建立 Presentation Profile、Theme Compiler、Theme Studio 三模式和 AI 主题验收矩阵。
- 登记 Desktop main window、native recovery、current-session capability 和 Computer Use PiP。
- 更新 `ling-design-system.md`、`desktop-shell.md` 的入口链接。

Exit gate：覆盖矩阵没有未归属入口，文档不存在实现者需要重新选择的组件或交互。

## Slice 1: UI Package Foundation

- 创建 `packages/ui-react`、构建脚本和 CSS exports。
- 建立 foundation tokens、Theme Pack tokens 和 Web/Desktop surface aliases。
- 将 Light/Dark 收敛为 `ling-light` / `ling-dark` 两个独立 Theme Pack，实现
  ThemeSelection、ThemeRegistry、schema validator 和内置 manifest。
- 实现 `ling-standard`、`ling-glass`、`ling-immersive`、`ling-illustrated` Profile registry。
- 实现本地图像分析、deterministic Theme Compiler、contrast 和 generated-content guards。
- 实现 Button、IconButton、表单、Overlay、Navigation、Feedback 和 Data Display。
- 实现 Icon wrapper、标准 Lucide action map 和 Logo 保护 guard。
- 建立 cascade layers、目标 CSS import 顺序和 package/conversation 样式出口。
- 建立 motion duration/easing tokens、Presence transitions 和统一 reduced-motion 规则。
- 实现全局 ToastProvider、InlineFeedback、FieldError，并建立 scope/dedupe/lifecycle 合同。
- 创建独立 E2E fixture 验证全部 primitives。
- 加入 guard：Radix 只能由 `ui-react` 导入。

Exit gate：package build/typecheck/test 通过，fixture 覆盖键盘、焦点、两个内置 Theme Pack、
四个 Presentation Profile、自定义主题 fixture、Compiler 和动效。

## Slice 2: Shared Interaction Migration

- 迁移 Ling Toast、CreateDialogShell、ActionMenuItem、Tooltip 和 SelectControl。
- 按全局反馈迁移矩阵先迁移 Profile、Plugin、Media Production，删除 browser `alert()`、
  Feature Toast viewport 和 Feature feedback timer。
- 迁移 Menu、Overlay 和反馈中的直接图标尺寸/颜色到 Icon/IconButton。
- 将 Toast 生命周期与 CSS 入退出场拆开，替换重复 overlay/spinner keyframes。
- 保留必要 API 与测试 selector，视觉由共享组件接管。
- 删除已无引用的旧 CSS，不建立第二套兼容视觉。

Exit gate：现有业务回调和状态不变，公共 overlay/feedback E2E 通过，页面成功与
Toast 不重复显示。

## Slice 3: Shell And Navigation

- AppShell、Sidebar、首次使用、全局错误和主题切换。
- 迁移首帧 bootstrap、新 root attributes、fixed/system resolution 和失败回退。
- 增加唯一 presentation layer owner、route policy、artwork preload 和 reduced transparency fallback。
- 统一 hit area、active、focus、menu、tooltip 和滚动。
- Sidebar expand/collapse 改为单一可反向 motion contract。
- 保持 ViewId、入口顺序和 Settings shell boundary。

Exit gate：`app.spec.ts`、`workspace.spec.ts`、`dark-mode.spec.ts` 和两种 viewport 通过。

### Slice U4D: Desktop Shell And Computer Use PiP

- 主 BrowserWindow 接入 UI 2.0 Theme/Profile 首帧 bootstrap，去除永久硬编码暗色背景。
- 原生 incompatible-daemon Retry/Quit 文案、键盘和中英文进入 Desktop Shell 合同。
- 建立 CompactDesktopWindow、CompactWindowHeader、StatusOverlay、ActionMenu 和 capability control。
- 三类会话的 current-session Computer Use 控制组迁移到共享 primitive。
- 先拆分 PiP `815` 行 renderer，再迁移为 React + `ui-react`；媒体/释放/来源校验逻辑不进入组件。
- PiP 接入 Theme snapshot，移除 `prefers-color-scheme` 和 production color literals。
- 保留 Hide、Close、Stop、permission、retry、window geometry 和 provenance 全部业务行为。
- U4D.6 补齐 Desktop auto-show preference、Windows Cua Driver provider health、owned-daemon
  startup failure recovery、Open task intent 和 host obstacle 的 UI/证据归属。
- screenshot harness 已从 5 个场景扩展为 14 个场景、28 张 Light/Dark 基线，覆盖 11 个
  权威 PiP 状态、3 种 live 尺寸和 reduced motion；行为测试与视觉证据继续分别记账。

Exit gate：Desktop Node/renderer/Web bridge 既有测试不回退；auto-show 保存/回滚、Windows provider
health、startup failure Retry/Diagnostics/Quit、Open task/obstacle lifecycle 通过；PiP 11 种状态、
3 种尺寸、Light/Dark、reduced motion 和 keyboard screenshots/E2E 通过。

## Slice 4: Conversation Surfaces

- 频道、普通对话、AI 队友私聊。
- 统一 Header、Feed、Composer、Summary、Terminal 和 Right Dock。
- `conversation-ui-react` 开始复用 `ui-react`，不复制通用控件。
- Summary/Dock/Terminal 支持快速反向开关和 drag transition suspension。

Exit gate：三类会话的尺寸、顺序、动效和可达状态有截图对比。

## Slice 5: Settings

- Settings shell、Default Authorization、Personalization、Interface、External Work、
  MCP、Skill Library、Archived、Startup Diagnostics 和 Workspace Tools 嵌入态。
- Interface Preferences 迁移为 Follow System + ThemePicker，接入本地主题导入/删除/预览。
- U7A：接入 Theme Studio、草稿、Quick mode、本地 Compile/Verify 和安装。
- U7B：接入 Generate/Advanced、能力过滤的 Planner/Artwork adapter、取消/重试和候选图。
- 深层 Tab、Dialog、Inspector、Details 和错误状态全部迁移。

Exit gate：Settings 内部操作不误切主壳；所有 12 个入口通过 E2E；Quick 断网可用，
Generate 只要求生图能力，Advanced 支持一模型或两模型。

## Slice 6: Management Surfaces

- AI Teammates、Council、Model Workbench、Plugin Manager、Automations。
- 统一列表、详情、创建、编辑、状态、主行动和危险操作。
- AI Teammates 按独立 Function ID 迁移；List/Create/Profile/Model/Skills/Memory/Permissions/Tasks/Activity 已 verified。
  Tasks A/A/A/A 恢复 Settings Tab、保留私聊消息转任务、只允许活动成员频道、不开自动运行，并按
  `currentRunId` 路由 Runs 或 Work Board；该路径未删除或降级自定义队友创建。
- Council A 只展示现有配置、成员可用性 readiness 和关系状态；不新增聚合 API、数据库字段或伪运行态。
  Create/Clone、List/Health、Members、Channels 与完整 Settings/Archive 已 verified；`Council Runtime` 作为
  未决产品能力独立登记，不阻塞现有可达 Web UI 2.0 closeout。

Exit gate：相应 feature E2E、i18n 和 `ling-light` / `ling-dark` 主题验收通过。

## Slice 7: Work And Media Surfaces

- Media Jobs、Media Production、Work Board、Runs、Threads、Approvals、Profile。
- Canvas 和 Timeline 保留领域布局，但基础控件、Overlay 和反馈必须共享。

Exit gate：媒体生成、运行诊断、审批和资料编辑真实流程不回退。

## Slice 8: Cleanup And Enforcement

- 删除兼容 facade、旧 class 和无引用 CSS。
- 删除局部 Toast provider、页面级 success/tip class 和无所有者的 global error banner。
- 删除 legacy `ThemePreference`、`data-theme`、旧 storage keys 和 Feature 主题 selector。
- 删除 `components.css`、`teammates.css`、`settings.css`、`providers.css`、`layout.css`、
  `sidebar.css` 和 `strict-console.css` 旧文件，使用最终 focused 目录。
- CSS 总量不超过 30,000 行；Feature 颜色字面量为 0；第一方 `!important` 为 0。
- 普通 UI action 不再使用 react-icons、PNG、emoji、字符图标或直接 Iconfont。
- 第一方 keyframes 不超过 6 组，animation declarations 不超过 15，raw duration/easing 为 0。
- 增加 UI import、legacy class 和 CSS ownership 检查。
- 增加禁止 browser alert、Feature feedback timer、Feature Toast viewport 和未登记 inline feedback 的 guard。
- 增加禁止 Feature `data-ui-theme` selector、主题硬编码颜色、可执行主题资源和未知 token 的 guard。
- 增加禁止 Feature Profile selector、模型输出 CSS/JS/HTML、未验证 token map 和 Theme Studio
  直接读取 provider secret 的 guard。
- 增加禁止 Desktop private generic Button/Menu visual、PiP production color literals、Web feature
  Electron import 和 PiP source file >500 lines 的 guard。
- 完成全产品截图和状态看板。

Exit gate：覆盖矩阵全部 `verified`，没有 feature 直接导入 Radix，没有新增 legacy class，
CSS/Icon budgets 达标，Logo 保护对象未变化。

主题附加 exit gate：`ling-light` / `ling-dark` 全产品证据通过，自定义 Theme Pack
无需 Feature CSS 即通过 primitive 兼容 fixture，四个 Profile 与三种生成模式通过，
Web/macOS/Windows 首帧与最终主题一致。

Desktop 附加 exit gate：main window 复用 shared Web，PiP/current-session control 使用 UI 2.0
primitives，macOS/Windows 主题、DPI、forced/reduced surface 和窗口证据通过。

## Required Commands

每个切片至少运行：

```bash
git diff --check
corepack pnpm --filter @ling-stack/ui-react build
corepack pnpm --filter @ling-stack/ui-react typecheck
corepack pnpm --filter @ling-stack/web check:i18n
corepack pnpm --filter @ling-stack/web typecheck
```

E2E 按迁移矩阵选择，最终必须跑完整 Web suite。
