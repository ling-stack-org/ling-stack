# UI 2.0 完成状态看板

## Status Legend

- `inventory`：已登记当前入口。
- `designed`：详细设计完成且无开放实现决策。
- `implemented`：代码迁移完成，自动化检查通过。
- `verified`：真实浏览器、主题、viewport 和证据通过。
- `blocked`：需要独立业务/API 设计。
