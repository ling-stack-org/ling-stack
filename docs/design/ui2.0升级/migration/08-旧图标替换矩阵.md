## Source-Level Rules

### Lucide

- 删除 Feature 直接指定任意 `size`、`color`、`strokeWidth` 的常规操作图标。
- Button/Menu/Field 内图标改由共享组件接管。
- 领域插图或图表 icon 可保留直接 Lucide，但必须使用 token 和批准尺寸。

### React Icons

当前唯一使用位于 `shared/conversation/blocks/TerminalReportBlock.tsx`，用于 Java 和技术栈
品牌/语言图标。该场景保留为批准例外，不得扩展到普通 UI 操作。

### Local SVG And Images

- `LingStackLogo.tsx`、favicon：`protected`。
- teammate avatar PNG：`content asset`，不转换为 Lucide。
- `ling-stack-gpt-image-2-icon.png`：产品/模型资产，可继续作为 identity icon，不用于按钮。
- 新增品牌 SVG 必须本地化、记录来源和授权，不允许远程加载。
