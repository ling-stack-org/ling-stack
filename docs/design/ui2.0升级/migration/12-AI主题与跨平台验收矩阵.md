# AI 主题与跨平台验收矩阵

## Scope

本矩阵将 Presentation Profile、快速/生成/高级模式、Theme Compiler、Theme Studio 和
Web/macOS/Windows 验收映射到实施切片。基础 UI 2.0 可以先完成 Theme Pack/Picker，
但 UI 2.0 主题系统只有本矩阵完成后才具备“用户生成主题”的完整能力。

## Delivery Slices

### U1: Theme Foundation Extension

- 增加 Presentation Profile types、registry 和四个内置 Profile。
- 增加 deterministic Compiler、图片分析、token derivation 和 contrast tests。
- 扩展 Theme Pack Schema 的 presentation、artwork slots、generation metadata。
- 在 `ui-primitives` fixture 验证 Profile 不改变 geometry。

Exit gate：纯函数测试、schema validator、contrast 和 Profile allowlist 通过。

### U4: Shell Presentation Layer

- AppShell 增加唯一 presentation layer owner。
- Home、Sidebar、Conversation、Settings、Overlay 接入 route policy。
- 接入 artwork preload、atomic commit、reduced transparency 和 platform fallback。
- Feature CSS 不读取 Profile ID。

Exit gate：四 Profile 在 Shell fixture 中无控件遮挡、无首帧闪烁、无业务状态变化。

### U7A: Theme Studio Quick Mode

- Interface Preferences 增加 Theme Studio 入口。
- 实现嵌套 Settings surface、draft controller、upload、local analysis 和 preview。
- 实现 Quick mode、compile、verify、install/install-and-use。
- Web IndexedDB draft/publish adapter。Desktop app-data draft/publish 保持独立
  `DESKTOP-THEME-PACK-PERSISTENCE-001` 待做，不由 Web evidence 关闭。

Exit gate：断网、无模型环境可从图片完成生成、预览和安装。

Current implementation：pure analyzer/Compiler/Profile、真实 Web decoder/sample/hash、draft repository、
revisioned reducer、production controller/surface、package-owned multi-surface Preview controls 与 D3=A
token-only publish 已实现。runtime artwork layer 按 D3=A 明确不进入 Quick；Desktop native generated-theme
publication 仍缺失。package `50/50`、focused substrate `4/4`、production Quick `2/2`。专项计划见
[`modules/settings/11-Quick-Theme-Studio-implementation-plan.md`](../modules/settings/11-Quick-Theme-Studio-implementation-plan.md)。

D3 决策：本地分析无法可靠识别可读文字、Logo/水印或 UI chrome。2026-07-30 已选择：

- A：图片仅用于 token/palette，runtime artwork 不发布（推荐）；
- B：用户明确 clean-background/rights/no-text-Logo-UI 确认后发布 artwork；
- C：视觉模型审核，需修改 Quick 的离线/无模型合同。

D3=A 已锁定并完成 Web 验收：图片只用于本地 palette/token 生成，不进入 installed theme assets，不生成
`manifest.artwork`，运行时不显示背景图。Quick 可继续接生产 Create theme 与 token-only publish；仍不得
伪造 `contentRisk=false`，因为该路径根本不创建 artwork 输入。

2026-07-30 production evidence：focused Quick `2/2`、substrate `4/4`、Web unit `13/13`，四张
Light/Dark 双尺寸截图位于 `evidence/features/quick-theme-first-run/`。Desktop native generated-theme
publication/restart 仍由独立跨平台门负责，不能由 Web IndexedDB 证据关闭。

### U7B: Generate And Advanced Modes

- 建立 Model Workbench capability adapter。
- 接入现有 image generation/media artifact 能力。
- 实现 Generate mode 的版本化 prompt template。
- 实现 Advanced mode Planner structured output、候选图、retry/cancel 和 recovery。
- 能力缺口按独立业务设计处理，不在 UI 层模拟。

Exit gate：一个生图模型可完成 Generate；Planner + Artwork 能完成 Advanced；失败可重试。

### U13: Enforcement And Full Verification

- 增加禁止 generated CSS/JS/selector/remote asset 的 static/runtime guards。
- 完成 Profile、Theme Studio 和 generated pack 的跨产品截图。
- 完成 Windows/macOS persistence、surface fallback 和 cold-start smoke。
- 删除 generation prototype compatibility code 和未使用模板。

Exit gate：本矩阵全部 `verified`，安全 blocker 不可绕过。

## Capability Preconditions

| Mode | Required | Optional | Disabled reason |
|---|---|---|---|
| Quick | local file + Canvas/decoder | worker/offscreen canvas | unsupported/invalid image only |
| Generate | image generation model | reference-image support, image edit | no configured image model |
| Advanced | structured multimodal Planner + image generation | same model for both, image edit | missing one required capability |

- 不能按模型名称推断能力。
- Model Workbench 中模型被停用、缺 Key 或检查失败时，Theme Studio 显示真实状态和修复入口。
- Theme Studio 不提供 API Key 输入框，避免复制模型配置流程。

## Source And Security Matrix

| Case | Expected result |
|---|---|
| clean 16:9 wallpaper | Quick allowed |
| UI screenshot | Quick direct install blocked; Generate/Advanced allowed as reference |
| image with readable text | warning/blocker based on result; cannot silently install |
| image with Logo/watermark | blocker unless protected Ling-owned approved asset, which theme still cannot replace |
| unauthorized identity reference | generation blocked |
| CSS/JS/HTML/font in bundle | rejected |
| external URL or file path | rejected |
| symlink/path traversal/oversize archive | rejected |
| Planner output contains selector/JS | parser rejects fields; blocker recorded |
| provider response contains secret | redacted from UI, logs and theme metadata |

## Compiler Test Matrix

- bright image、dark image、single-color image、transparent image。
- left-safe、right-safe、centered、ultrawide、portrait source。
- high-frequency wallpaper、low-contrast wallpaper、text-like edges。
- invalid MIME、truncated file、huge dimensions、metadata-heavy image。
- accent clashes with danger/success semantic colors。
- contrast auto-repair succeeds、repair limit exceeded。
- Profile unsupported slot、unknown Profile、missing artwork、decoration without alpha。
- same input produces stable manifest/token map across Web/macOS/Windows tests。

可达状态必须一致。

## Completion Gate

- Quick、Generate、Advanced 三种模式均有真实成功和失败证据。
- Quick 模式断网可用；Generate 不强制文本模型；Advanced 支持一模型或两模型配置。
- Presentation Profile 可以产生明显全局变化，但不能改变业务布局或受保护品牌。
- UI screenshot/effect mockup 不能绕过生成步骤直接成为背景。
- 所有输出经过同一个 Compiler、registry 和 publish transaction。
- Web、macOS、Windows 使用同一主题合同，无平台私有 Theme Pack fork。
- 没有半完成主题、首帧闪烁、焦点/滚动丢失或 overlay 被背景遮挡。
