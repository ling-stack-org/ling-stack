图标标准行动映射见 [Icon 系统与功能映射](../components/11-Icon系统与功能映射.md)，旧图标

## Global Mapping

| Existing pattern | UI 2.0 target | Migration notes |
|---|---|---|
| `<button className="primary-button">` | `<Button variant="primary">` | 保留 type、disabled、callback |
| secondary/compact button classes | Button secondary/ghost + size | 不通过 class 组合尺寸 |
| icon-button + title | IconButton label/tooltip | label 必填，hit area 统一 |
| direct Lucide size/color | Icon/IconButton | 尺寸、stroke、tone 由组件统一 |
| react-icons action icon | Lucide action map | 品牌/语言例外除外 |
| PNG/emoji/character action | Lucide or approved local SVG | 普通操作禁止位图/字符 |
| raw input/textarea | Input/Textarea inside Field | primitives implemented；Settings representative migration complete，remaining pages U3 |
| SelectControl（deleted） | Select | P3 历史基线 43 callers 先共享 primitive visual；T13-P.3-R 最终 `0/0`，调用方直接使用 shared `Select` |
| custom overlay + role dialog | Dialog/Drawer | Radix focus/portal/dismiss |
| custom absolute menu | Menu | 键盘和 collision 统一 |
| CSS data-tooltip | Tooltip | hover/focus，Portal |
| status pill classes | Badge/StatusIndicator | feature 派生 tone 和 label |
| inline-error paragraph | InlineFeedback error | 保留修复行动 |
| local toast/banner | Toast hook | 阻塞错误仍 inline |
| empty panel/card | EmptyState | compact，不撑高 |
| loading text/spinner class | Spinner/Skeleton | 只作用于真实 busy scope |
| ad-hoc list row | DataRow | identity/status/actions slots |
| details/card stack | InspectorSection | summary-first disclosure |

## Menu/Popover Mapping

Sidebar、provider row、teammate row、automation popover、composer permission、workspace file open
全部迁到 Menu/Popover/Tooltip。Summary popover 属于产品级 Popover，保留专属内容但复用 shell。

当前进度：Automation popover 已迁共享 Popover；SettingsSubnav 已迁 Tabs；Media Production
view switcher 已迁 SegmentedControl。Sidebar Menu/Tooltip 和三类对象行已完成 P4.1-P4.2；
provider/management teammate row 和 Summary 仍按对应页面切片迁移。

## Feedback And Data Display Progress

- Web `LingToastProvider` 已收敛为共享 Toast 的 i18n adapter；`global-toast.css` 和 Profile 局部
  Toast ownership 已删除。
- Profile、Plugin、Media Production 是首批共享反馈代表面；阻塞失败继续使用 InlineFeedback。
- `OperationEmptyState` adapter 已在 T13-P.2-D 归零并删除；Council 最后一个 consumer 直接使用 shared
  `EmptyState`，guard 当前为 `0/0`。后续 Feature 不得重新引入同义 empty-state wrapper。
- Badge、Skeleton、DataRow、Table、InspectorSection 共享合同已实现，但业务列表的旧 class/CSS
  仍由后续模块切片逐页删除，不能据此宣布全产品迁移完成。

## Test Selector Rule

优先使用 role、accessible name、aria-current 和 stable data attribute。旧视觉 class 不能继续
作为唯一 E2E selector。迁移期允许双 selector，完成后删除 legacy selector。
