批准的最终 keyframes 仅限 Spinner、Skeleton shimmer、必要状态 pulse，以及 Radix Presence 需要的
测量型 Collapsible open/close pair。Dialog、Drawer、Menu、Popover、Tabs 和 Sidebar shell 不使用
不可打断的单向 keyframe；Collapsible 必须通过 `data-state`、rapid reversal 和 reduced-motion 验收。

## Verification

- 搜索 `transition`、`animation`、`@keyframes`、raw `ms/s`、`transform` 和 reduced motion。
- Playwright 使用 normal/reduced motion 两个 context。
- Rapid toggle：在 enter 完成前触发 close，再次 open，最终状态与最后输入一致。
- Drag：移动中无 transition lag，释放后尺寸受 min/max 限制。
- 截图/视频不得出现 Summary 闪失、Drawer 跳位、focus 丢失或页面重排。
- Desktop：rapid Show/Hide/Stop、theme/locale revision、renderer reload 和 media recovery 均不产生
  action flash、Header 增高或 capture 重建；Esc 不触发 Stop。
- PiP：live chrome hover/focus 可打断，non-live status 不随 hover 隐藏，reduced motion 只使用直接
  opacity change。
- 每个迁移 PR 记录删除 keyframes、替换 tokens 和保留例外。
- P4.3：Radix 初始 mount 会为高度测量设置 inline `animationName=none`；normal motion 必须在真实
  用户切换后检查，不能用初始 mount 的 computed style 代替交互验收。
- P6B.2：model/thinking Menu 的 open/close、Esc 和 focus return 由共享 Radix Menu owner；Feed 跳到最新、
  Composer focus、upload 和 sending/stopping 状态都不得改变 page/Header/Composer 外部几何。
- P6B.3：Normal Dock 复用 P5.2 controller/Presence，不新增独立 enter/exit keyframe；Back 只切换 page stack，
  Close 才收起 Dock。resize 期间 transition 为 `0s`，释放后 clamp；四张 changed-state 证据不得截在中间态。
