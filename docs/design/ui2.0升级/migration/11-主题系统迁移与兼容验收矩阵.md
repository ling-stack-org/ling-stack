## Legacy Preference Mapping

| Current value | New selection |
|---|---|
| `system` | `{ mode: "system", lightThemeId: "ling-light", darkThemeId: "ling-dark" }` |
| `light` | `{ mode: "fixed", themeId: "ling-light" }` |
| `dark` | `{ mode: "fixed", themeId: "ling-dark" }` |

- 迁移只读取 legacy value 一次，写入新 client-local selection 后标记 migration complete。
- 不把任意 Theme Pack ID 写入现有 daemon `theme: system|light|dark` contract。
- 旧 localStorage key 在两个切片内只读兼容，U13 删除。
- 旧值无效时使用默认 System selection，不猫测主题 ID。

### Selector Rules

- 内置 Theme Pack selector 只能出现在 `@ling-stack/ui-react` theme layer。
- Feature CSS 中 `data-theme`、`data-ui-theme` 和具体 Theme Pack ID 目标为 0。
- Feature CSS 中 `data-ui-presentation` 和具体 Profile ID 目标为 0。
- `data-color-scheme` 只能在 bootstrap、native-control adapter 和明确领域集成层使用。
- 遇到需要主题差异的组件时，新增语义 token，不新增主题 selector。
- color literal 只能位于 built-in Theme Pack manifest/token source 和批准的品牌资产。

## Theme Compatibility Levels

| Level | Scope | Required verification |
|---|---|---|
| Built-in full | `ling-light`, `ling-dark` | all Views, Settings, overlays, representative deep states |
| Official additional | bundled future themes | primitive fixture + Shell/Settings/conversation/management smoke |
| Local imported | user bundle | schema/contrast/security fixture + representative preview; no product guarantee beyond token contract |
| Invalid/incompatible | rejected or disabled | fallback, diagnostics and removal/reimport paths |

引入 Theme Pack 不应导致对每个用户主题运行全量产品 E2E。可扩展性由语义 token
合同、共享 primitive fixture 和禁止 Feature 主题 selector 来保证。

## Reachable States

- fixed `ling-light`、fixed `ling-dark`、system resolved light、system resolved dark。
- OS appearance changes while system/fixed。
- theme apply loading、success、failure and rollback。
- imported theme ready、invalid、missing asset、incompatible schema、deleted while selected。
- browser storage unavailable、IndexedDB unavailable、Desktop store unavailable。
- first load、hard refresh、Desktop cold start、window reopen、renderer reload。
- Dialog/Drawer/Menu/Popover/Toast open during switch。
- long page scrolled、composer draft、terminal open、right dock resized during switch。
- Web、macOS Desktop、Windows Desktop、Light/Dark native controls。

## Completion Gate

- `ling-light` 和 `ling-dark` 作为两个完整独立 Theme Pack 实现。
- `System` 只保存映射和解析策略。
- 新增 Theme Pack 不需要修改 Feature CSS 或共享组件 JSX。
- 切换主题不改变 geometry、scroll、focus、open overlays 和业务状态。
- 首帧主题与最终解析主题一致，无黑闪/白闪。
- Web、macOS 和 Windows 使用同一 manifest/token 合同。
- 导入主题只能通过经验证数据改变视觉，无代码执行或任意 CSS 注入。
- 四个 Presentation Profile 不改变 geometry、Logo、业务内容或 Feature CSS ownership。
- Quick/Generate/Advanced 生成主题通过同一个 Compiler 和 Registry transaction。

AI 生成主题的详细状态和证据见

## P7C.1 Web Import Closeout

- `UI-THEME-IMPORT-001` and `SETTINGS-INTERFACE-THEME-IMPORT-001` are Web `verified` for semantic
  tokens plus one isolated preview. Runtime artwork remains outside the accepted package contract.
- Web IndexedDB v2 owns manifest, package metadata and preview Blob atomically; v1 manifest migration,
  refresh restore, reimport rollback and active delete fallback are verified.
- Import does not add Feature Theme ID selectors, arbitrary CSS/JS/HTML/SVG/font/remote URL or Logo replacement.
- Evidence: `ui2-settings-theme-packages.spec.ts` `5/5`, selected regression `83/83` and six original-size
  screenshots in `evidence/settings/theme-packages/`.
- `DESKTOP-THEME-PACK-PERSISTENCE-001` remains `inventory`. Native `appData/themes/<id>`, staging/atomic
  rename, typed IPC, packaged restart restore and macOS/Windows evidence are mandatory follow-up work.
