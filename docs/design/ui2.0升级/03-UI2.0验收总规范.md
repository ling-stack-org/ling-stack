# Ling UI 2.0 验收总规范

## Status Levels

- `designed`：合同已确定，尚未形成可达实现。
- `implemented`：代码已接入，但真实浏览器或目标平台证据不完整。
- `verified`：当前 Web 功能通过本规范要求。
- `release-ready`：目标 packaged Desktop 平台通过发布清单；不能由 Web verified 推导。

## Definition Of Done

一个功能只有同时满足以下条件才能标记 Web `verified`：

1. 使用共享 primitive，或有明确的领域组件所有权。
2. 默认、loading、empty/no-result、success、warning、error、stale、长内容和 destructive 状态可达。
3. `zh-CN`、`en-US` 语义一致，不泄漏 raw ID、路径或内部错误。
4. 全部内置主题完成可读性与布局检查；主题仅改变批准的组件外观，不改变控件高度、命中区域和业务语义。新组件/模块满足[主题接入合同](../component-theme-presentation.md)。
5. `1440x960`、`1280x800` 无横向溢出、遮挡或操作截断。
6. 键盘、焦点恢复、ARIA、Esc 和 reduced motion 符合合同。
7. 相关单元/E2E 通过，真实浏览器 console 与 pageerror 无新增问题。
8. UI 变更完成浏览器交互和截图目检；证据存放在 CI/Release artifacts，不写回设计目录。

## Visual And Content

- 第一屏能识别当前对象、需处理状态和唯一主行动。
- 不出现重复标题、说明墙、嵌套卡片、彩色状态堆叠或无意义刷新按钮。
- 正常状态和 0 数量默认隐藏；异常、审批和阻断持续显示。
- 同级按钮、图标、文字和输入控件基线一致；IconButton 命中区域至少 `32x32px`。
- 表格、列表、Canvas、Inspector 和 Dialog 有唯一滚动 owner；无固定空 gutter 或 document 横向滚动。
- Dark 使用分层深灰，不以大面积纯黑覆盖 panel、表格、输入和设置页面。
- 长文本截断时有可访问的完整信息；文字不竖排、不遮挡、不把动作推出容器。

## Interaction And Feedback

- Dialog/Drawer 锁定焦点并在关闭后恢复 trigger；busy destructive action 阻止重复提交。
- Menu、Tabs、SegmentedControl 和列表选择具备正确键盘语义。
- Tooltip 不承载完成任务所需的唯一信息。
- Toast 只用于短暂结果；字段、对象、阻断和失败使用 scoped InlineFeedback。
- loading 只影响发起动作；刷新保留旧数据，迟到响应不能覆盖新对象或新请求。
- disabled 状态提供可理解原因；保存、冲突和网络失败不得清空用户输入。
- hover 不改变 AI 普通正文背景；警告、审批和状态卡片不依赖 hover 才可见。

## Motion And CSS

- 使用 motion token，禁止 `transition: all`、摇晃、弹跳、列表 stagger 和装饰性循环动画。
- 快速反向操作以最后输入为准；展开/收缩不产生二次动画或布局跳动。
- reduced motion 取消位移、缩放、pulse、shimmer 和 smooth scroll。
- Feature 不命中 `.ling-ui-*` 内部 selector，不按具体主题/Profile ID 写分支。
- 新颜色来自 semantic token，不新增逃逸 z-index、未分层全局 CSS 或重复 dark override。
- 单个生产 CSS 文件硬上限 800 行；超过时按责任拆分。
- 共享组件的默认/交互外观只有一个所有者；页面覆盖、写死圆角/阴影或变量遮蔽不能作为主题适配。新增参数必须有通用默认值与实际消费组件。

## Theme And Desktop

- 主题可以改变语义 token、已批准的组件圆角/边界/阴影/材质、Desktop 表面与 artwork；不改变布局、文案、Logo、图标或状态机。
- 首帧 theme dataset、computed token 和 native color scheme 一致；失败原子回退。
- 当前只提供官方内置主题，Quick/Generate/Advanced 与导入主题不是可达产品能力；历史安全测试不代表这些入口重新开放。
- 自定义图片/视频背景是独立偏好，按[背景合同](../theme-background-hardening-plan.md)验证；普通工作区背景可见，正文与受保护表面保持可读。
- Light/Dark/Breeze/Night/Ocean/Journey 及背景有/无时检查新增模块；切换不能留下上一主题的样式或丢失草稿/焦点/滚动。受影响的普通会话、频道与私聊比较实际 computed style。
- token 接入、功能验收、用户美术确认分别记录。文档要求不等于现有 lint 自动覆盖全部页面，需要对应交互与截图证据。
- Desktop native publication 只能按真实已完成能力标记状态。
- packaged Desktop 还必须验证重启持久化、签名、DPI/high contrast、reduced transparency、窗口 chrome、
  PiP 几何、IPC 失败恢复和原生辅助技术。

## Hard Stops

- 为视觉迁移新增或改变 API、数据库、权限、审批、安全、provider authority 或运行状态机。
- 使用 localStorage 保存权威业务状态。
- 恢复命令式 overlay、浏览器 `confirm()`、远程 Iconfont 或普通操作 PNG/emoji 图标。
- 用 Web 截图宣称 Windows/macOS packaged、签名或真实 Computer Use 已通过。
