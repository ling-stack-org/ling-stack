## Product Boundary

现有 Media Job 是单次生成任务；媒体生产台在其上增加项目、场景和场景运行关联，不替代任务、产物、
审计或模型工作台。当前是分镜画布，不是时间线编辑器，不提供拼接、转场、字幕、配音或 FFmpeg 导出。

## Generation Jobs

- 任务列表显示操作、模型、状态、创建时间和产物；详情展示输入摘要、结果、失败和下载。
- 图片/视频预览使用真实 artifact。用户点击视频预览后进入可播放状态并自动尝试播放；浏览器阻止时
  显示明确播放控件，不伪造正在播放。
- running、waiting、failed、cancelled、completed 由后端权威状态决定；刷新和轮询保留旧数据。
- Cancel/retry 只在 adapter/route 支持时显示；失败不清除任务和产物历史。

## Production Studio

- 默认进入画布优先布局。项目列表和场景 Inspector 是悬浮、可展开/收缩的面板，不永久压缩画布。
- 场景由 `sortOrder` 决定生成顺序，节点坐标只负责画布排布。
- 场景支持标题、提示词、模型、比例、时长和真实能力允许的图片输入；未知模型不能通过手填字段启用
  图片能力。
- 图片从场景内上传或由既有图片产物导入，保存到当前媒体项目素材库，并可被同项目多个场景复用。
- 没有图片时隐式为文生视频；有图片时显示“参考图片 / 起始画面”用途，具体选项和数量由模型能力决定。
- 素材区位于提示词下方，使用稳定单行缩略图与内部滚动，不把检查器或页面撑出横向滚动。
- 上传、导入和绑定必须保留发起时的项目/场景身份；未完成或失败的图片输入同时阻止单场景和批量运行。
- 新建、复制、删除、排布和选择素材不触发付费生成。每次运行创建新的标准 Media Job 和历史记录。
- 单场景运行按钮保持可点击；提示词为空时点击后就地提示，不下发任务。点击运行先提交当前焦点内草稿，
  不要求用户额外点击空白处。
- “按顺序生成”只提交可运行场景，并继续遵从各模型并发限制。

## Canvas And Panels

- 画布使用稳定网格背景、MiniMap、缩放和 fit-view；纯白背景不得吞掉节点、连接线或 MiniMap。
- 左右面板的展开/收缩只发生一次，由单一状态 owner 驱动；CSS 与 React 不叠加第二套宽度动画。
- 项目删除、场景删除使用可见按钮和共享确认 Dialog；成功后选择相邻有效对象。
- 面板和列表内部滚动，页面壳不滚；箭头排序使用紧凑 IconButton，不使用宽文字按钮。

## Model And Runtime Boundary

- 模型工作台是唯一模型入口。`video_generate` 保持现有 operation；能力由 resolver 与专用 adapter 声明。
- 图片入口只在真实 Adapter 声明 `first_frame` 或 `reference_image` 后显示；模型只支持一种用途时不显示
  无意义的二选一控件。
- 模型切换不会静默改写图片角色；不兼容时保留输入、显示修复提示并阻止生成。
- 长任务使用持久化执行句柄恢复 poll/cancel/collect；浏览器请求不等待完整视频生成。
- 不改变旧 Media Job、artifact、密钥、安全策略和 provider 状态机。

单场景/批量运行、取消、失败恢复、视频预览、Light/Dark、`1440x1000`、`1280x800` 和 packaged Desktop。
