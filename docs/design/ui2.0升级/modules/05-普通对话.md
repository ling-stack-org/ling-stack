# 普通对话

## Goal

普通对话向频道的核心交互对齐，但不显示成员、治理和频道任务能力。页面不能退化为只有
消息区和孤立展开按钮的简化版本。

## Function Points

- `CONV-NORMAL-HEADER-001`：Search、Refresh、Summary、Terminal、Details。
- `CONV-NORMAL-SEARCH-001`：消息正文、附件和运行标题搜索。
- `CONV-NORMAL-SUMMARY-001`：workspace、线程、运行、附件和上下文摘要。
- `CONV-NORMAL-TERMINAL-001`：当前 cwd 终端。
- `CONV-NORMAL-DOCK-001`：Review、Evidence、Files 和 Context。
- `CONV-NORMAL-FEED-001`：历史、流式、运行和失败。
- `CONV-NORMAL-COMPOSER-001`：输入、附件、权限、发送和停止。
- `DESKTOP-CUA-CONTROL-001`：Desktop current-session Computer Use 状态、Show/Hide 和 Stop。

## Layout And Interaction

Header、conversation width、Popover、Bottom Panel、Right Dock 与频道使用同一尺寸和动效。
按钮默认 icon-only。Summary 与 Dock 独立；Dock 打开时 Summary 位移但不卸载。

Desktop capability 使用与频道相同的固定 Header slot 和共享组件，不能在普通对话重新实现文字
按钮。slot 的出现/隐藏不改变 toolbar action geometry；失败反馈锚定于 capability control，
不占搜索、状态行或消息区高度。

## States

无线程、加载、无刷新目标、无 cwd、搜索无结果、streaming、queued、approval、failed、
recovered、attachments unavailable。禁用按钮提供明确 title/reason。

## Current And Target

当前 `ConversationHome.tsx` 只接入共享 toolbar、summary、dock、terminal 和 conversation
components，不继续增加主要 UI 逻辑。业务刷新和发送 callback 保持原样。

## Tests

`app.spec.ts`、`composer-token.spec.ts`、`dark-mode.spec.ts`。与频道截图对比 header、消息列、
summary、dock 和 terminal。`desktop-computer-use-bridge.spec.ts` 对比三类会话的 capability
control、32px actions、Header bounding box 和命令失败。

## P6B Implementation Slices

### P6B.1 Header And Search

Function IDs：`CONV-NORMAL-HEADER-001`、`CONV-NORMAL-SEARCH-001`。

Status：`verified`（2026-07-19）。`NormalConversationHeader`、controller、focused CSS、三类搜索、
semantic Toolbar frame、Desktop Portal obstacle、双主题/viewport 截图和联合回归均已闭环。

- Header 高度、底边、背景、左右 slot 和 `Search / Refresh / Summary / Terminal / Details` 顺序以已验证
  Channel Header 为基准；普通对话左侧显示稳定会话身份，不伪造成频道或队友。
- Search 必须复用 `ConversationHeaderSearch` 的共享 Input/IconButton 边界，不保留 raw label/input/button
  第二套实现。打开后输入自动获得焦点；Clear 保持展开并恢复焦点；Esc 关闭并清空。
- 搜索覆盖消息正文、附件文件名和关联 run 标题/provider；无结果使用明确 EmptyState，不显示“还没有消息”。
- Refresh 只让自身 loading；Search focus 不改变 48px Header 外高，长标题和全部 actions 在 1280 宽度不重叠。
- 抽 `NormalConversationHeader` 纯展示组件；`ConversationHome.tsx` 只保留业务数据和 callback 接线。
- 将普通对话页面 CSS 从已超过 800 行的 `conversation-home.css` 迁到 focused
  `normal-conversation.css`，同步删除源 selector；共享 Header Search CSS 归 `conversation-toolbar.css`。

验收：新增 `ui2-normal-conversation.spec.ts`，覆盖 1440 Light、1280 Dark、keyboard、focus、搜索三类来源、
无结果、Clear/Esc、Refresh scoped busy、Header/Feed/Composer 几何、console 和 document overflow。
