## Scope

三个会话面共享 Header、消息 Feed、Composer、权限控件、搜索、Right Dock 和运行反馈。业务模型、
成员关系和发送路由保持各自领域所有权；共享视觉不得把三者的模型语义混为一谈。

模型创建、默认值和删除校验以
[会话模型绑定合同](../../conversation-model-binding-and-creation-validation.md)为准。

## Surface Differences

| Surface | Identity | Model | Settings |
|---|---|---|---|
| 普通对话 | 内置 Ling Agent | 当前对话的 Ling Agent 模型 | 左上角菜单进入，与私聊使用同一设置壳 |
| 频道 | 频道 + 成员 | 频道保存自己的“Ling Agent 模型”；成员使用各自模型 | 左上角菜单；成员模型不在频道内批量覆盖 |
| 队友私聊 | 当前队友 | 队友固定模型或明确继承的工作区默认 | 左上角菜单，提供重命名、设置和打开上下文 |

- 未配置模型时，在 Composer 上方使用同一产品化状态条；已有可运行模型时不常驻状态。
- 新建频道和队友必须提交可运行模型。默认模型只负责预选，不覆盖已有对象的显式选择。
- 当前对象主动选择“完全访问”时，该动作本身可构成当前会话确认；继承工作区默认时的确认规则由
  安全合同决定。频道、普通对话和私聊只展示权威结果，不自建权限状态机。

## Header And Feed

- Header 只常驻身份、必要导航和搜索/详情等操作；模型、记忆、附件为正常值或 0 时隐藏。
- 频道和私聊中的用户头像使用用户配置，缺失时使用系统默认；队友使用自身头像。
- 普通对话不显示用户或 Ling Agent 头像；各会话面的头像显示由共享 Surface Policy 决定，页面 CSS 不得单独隐藏身份或重定义消息语义。
- 用户消息使用稳定浅灰气泡；AI 普通回复透明无边框；状态卡片持续显示自己的背景和边框。
- 头像与普通正文、卡片正文统一顶部对齐。消息操作只在 hover/focus 时出现，正文不因 hover 变色。
- 队列引导发送后立即从队列移除，并作为普通用户消息进入 Feed；不显示特殊“排队引导”标签。
- 不渲染无信息量的“收到”“静默收到”等 Agent 回执。

## Composer And Permissions

- Composer 不用大块空白预留附件、权限或提示区域；只有真实状态出现时才占用空间。
- 发送、停止、附件、权限和模型阻断使用稳定尺寸。输入超限后内部滚动，不遮挡最后一条消息。
- 阻断保留草稿；发送成功立即建立用户消息，不等待 Agent 完成才更新本地队列。
- 普通对话、频道和私聊使用同一模型阻断状态条；按钮只改变各自领域的配置入口，不改变模型归属。
- 警告、审批和安全确认靠近 Composer 或具体运行对象，raw error/route/request ID 默认折叠。

## Channel Workspace

- 频道可拥有消息搜索、Summary、Terminal、Right Dock 和工作区工具，但展开状态彼此独立。
- Right Dock 聚合 Review、Evidence、Files、Context 等当前真实能力；Dock 宽度可调整，页面本身不滚。
- Terminal 是明确打开的底部工作区，不通过永久白色占位挤压 Feed。
- Ling Agent 是频道可见叙述者；Observer 或后台协调状态不得伪造普通成员消息。

## Private Chat Details

- 私聊设置与频道使用同一 Shell、标题层级和表单密度，不因模型已配置而失去设置入口。
- 设置默认只保留资料、模型、频道、技能，以及有真实高级能力时的工具与权限。
- 任务、动态、独立记忆、独立危险操作和无可操作 MCP 空页不进入默认页签。
- 上下文从左上角菜单直接打开 Right Dock；记忆摘要属于详情，不制造常驻 Header 标签。

## Acceptance

覆盖长消息、流式输出、附件、模型缺失、权限确认、审批、队列发送、Right Dock、Terminal、
Light/Dark、键盘、Esc、`1440x960` 和 `1280x800`，并确保 console/pageerror 为空。
