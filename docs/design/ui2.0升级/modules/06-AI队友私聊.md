# AI 队友私聊

## Goal

AI 队友私聊使用与频道相同的会话骨架，同时保留队友身份、记忆和私聊上下文。顶部不堆叠
Review、Evidence、Files 或 Settings 文字按钮。

## Function Points

- `CONV-TEAMMATE-HEADER-001`：身份、Search、Refresh、Summary、Terminal、Details。
- `CONV-TEAMMATE-SEARCH-001`：私聊正文、附件和回复搜索。
- `CONV-TEAMMATE-SUMMARY-001`：队友、workspace、最近回复、附件、记忆和上下文。
- `CONV-TEAMMATE-TERMINAL-001`：workspace cwd 终端。
- `CONV-TEAMMATE-DOCK-001`：Context、Review、Files、Activity、Browser、Terminal；Browser/Terminal 是具体
  evidence page，不提供泛化 Evidence launcher。
- `CONV-TEAMMATE-FEED-001`：私聊历史、流式和失败恢复。
- `CONV-TEAMMATE-COMPOSER-001`：mentions、附件、发送、停止和排队。
- `DESKTOP-CUA-CONTROL-001`：Desktop current-session Computer Use 状态、Show/Hide 和 Stop。

## Layout

身份在标题区，不改变工具条按钮节奏。消息和 Composer 宽度与频道一致。Summary 在 Dock
打开/收缩时使用频道同款位移动效，不先隐藏。Dock 支持左右拖动。

Desktop capability 位于与频道、普通对话相同的 Header slot。队友身份和 capability control
使用 `minmax(0, 1fr)` 分配空间，长名称截断，actions 不折行。命令失败使用锚定反馈，不把身份、
状态行或工具条向下推；Show/Hide 与 Stop 保持独立语义。

## States

队友 unavailable/hidden、无 workspace、无 cwd、无记忆、搜索无结果、刷新、流式、失败、
附件不可用和上下文 stale。

## Current And Target

当前 `TeammateWorkspace.tsx` 体积过大，只接入 `ui-react` 和共享 conversation controllers。
队友数据、记忆和业务 tabs 保持 feature-owned。

## Tests

`teammates.spec.ts`、`composer-token.spec.ts`、`dark-mode.spec.ts`。与频道对比工具条、摘要、
Terminal、Dock 动画、宽度和 icon alignment。`desktop-computer-use-bridge.spec.ts` 还验证私聊
slot、32px actions、状态切换和 Header 稳定性。

## Migration Checkpoint

P5.2 已验证 `CONV-TEAMMATE-SUMMARY-001` 和 `CONV-TEAMMATE-TERMINAL-001`；
`CONV-TEAMMATE-DOCK-001` 的共享 open/close/resize/motion 已实现，Context/Review/Files/Activity/
Browser/Terminal 深层状态仍由 P6C 关闭。私聊没有真实 proposed-plan 输入，因此 Plans 默认不显示；
Browser/Terminal 已承载具体 evidence，generic Evidence 保持 absent。P6B.1 Desktop 回归已补证 Summary 与 Terminal 同时保持、Portal Summary
上报 canonical `popover`；Header、Search、Feed、Composer 和 Memory 内容仍保持 open。

### P6C.1 Header And Search

Function IDs：`CONV-TEAMMATE-HEADER-001`、`CONV-TEAMMATE-SEARCH-001`。

Status：`verified`（2026-07-19）。共享 Header controller/Search、五类索引、Clear/Esc/focus、切换队友清空、
局部 Refresh、focused CSS、双主题/viewport 证据和联合回归均已闭环。

- 保留队友头像、名称和必要状态，Header 固定 48px；长名称使用 `minmax(0, 1fr)` 截断，不挤压 actions。
- action 顺序固定为 `Search / Refresh / Summary / Terminal / Details`，全部 icon-only；Desktop current-session
  capability 使用共享 start slot，不改变工具条几何。
- Search 复用 `ConversationHeaderSearch`，覆盖正文、附件名、workspace file ref、link preview 和 AI 回复；
  Clear 保持展开并恢复焦点，Esc 清空关闭，切换队友清空查询。
- Refresh 只让自身 busy；打开 Search 不卸载 Summary/Dock/Terminal，也不改变 Header 外高。
- 抽 Header controller/view-model 和 focused CSS；不把 teammate data、refresh API 或 Desktop bridge 放进
  `TeammateChatHeader`。
- `ui2-teammate-conversation-header.spec.ts` 覆盖 Light 1440、Dark 1280、长名称、五类搜索来源、
  no-result、Clear/Esc/focus、scoped Refresh、32px actions、console 和 overflow。

证据：[P6C.1 Teammate Header And Search](../evidence/conversations/teammate-conversation-header/metadata.md)。

### P6C.3 Context And Dock Deep States

Function IDs：`CONV-TEAMMATE-CONTEXT-001`、`CONV-TEAMMATE-DOCK-001`。

Status：`verified`（2026-07-20）；共享 open/close/resize/motion 与私聊全部深层页面均已闭环。

- Context 汇总队友身份、workspace、最近回复、附件、Memory 和私聊运行；缺失/空/stale 必须诚实呈现。
- Review、Files、Activity、Browser、Terminal 只使用现有 message/run/action/report/attachment/file-ref/
  web-evidence 数据；没有真实数据时显示 EmptyState，不伪造 Channel capability。
- 当前 `contextNode` 被错误接到 `activityNode`；本切片必须拆成独立 Context 与真实 Activity page。
- Browser/Terminal 是具体 evidence page，generic Evidence launcher 保持不存在；当前无 private proposed-plan
  输入，Plans launcher 通过共享展示 capability 关闭，不显示无意义的 `No plans`。
- 不显示成员栈、governance、Channel settings、New task launcher 或 Channel-only plan scope；消息行现有
  “Create task”是真实跨频道动作，不属于 Dock launcher，必须保留。
- 抽 `TeammatePrivateChatDockPages`、`TeammatePrivateChatWorkspacePanels` 和 page shell；复用共享
  `WorkspaceRightDock`、Presence、pointer capture、clamp 和 Bottom Terminal。
- 新增 `ui2-teammate-conversation-dock.spec.ts`，逐 launcher 覆盖 loaded/loading/empty/error/detail、
  Back/Close、page request、长内容、resize、Esc/focus、reduced motion；同时断言 Plans、generic Evidence
  和 Channel-only controls absence。

当前真实数据映射：Context 使用 `directWorkspace`、最近 AI 回复、私聊附件和 Memory；Review/Files 使用
`visibleMessages`、`runs`、附件和 file refs；Activity 使用 `activityItems`、`executionActions`；Browser/
Terminal 使用 web evidence、`terminalReports`、execution actions 和有效 cwd 的 terminal session。顶部
Terminal 控制底部面板，Dock Terminal 展示 linked shell evidence/session，两者不互相替代。

- 私聊 run 按 linked thread/run ownership 过滤，Dock 使用完整私聊历史，不受 Search 过滤结果影响；
- Review、Files、Browser、Terminal 只投影真实私聊数据，Plans 与 generic Evidence 保持 absent；
- `TeammateWorkspace.tsx` `2,502 -> 2,489`，`TeammatePrivateChatSurface.tsx` `181 -> 173`；新增
  `TeammatePrivateChatDockPages.tsx` 217 行，纯 projection `teammate-private-dock.ts` 428 行；
- `teammates.css` `4,800 -> 4,735`、`sidebar.css` `1,850 -> 1,849`，新增 247 行 focused
