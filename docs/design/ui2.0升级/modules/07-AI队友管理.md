# AI 队友管理

## Product Structure

默认导航为：`资料 | 模型 | 频道 | 技能`。只有存在真实高级工具、MCP 授权或权限异常时，增加
`工具与权限`。独立任务、动态、记忆、权限、MCP 和危险操作页签不进入普通用户默认导航。

受保护的 Ling Agent 按能力隐藏不可编辑入口。关闭页面或切换队友时，旧请求和旧错误不得写入新对象。

## Profile

- 资料页编辑头像、名称、角色/说明和启用状态；布局使用一个紧凑身份区加结构化表单。
- 低频“停用队友、删除队友”进入资料页底部的“管理队友”，使用共享确认 Dialog。
- 删除必须遵从服务端引用校验；受保护队友不显示删除。
- 私聊左上角菜单提供重命名快捷项、设置和打开上下文，设置入口不依赖模型是否已配置。

## Model

- 模型是核心必填配置。未配置或不可运行时显示与频道一致的 Composer 上方修复提示。
- 队友显式选择优先于工作区默认；后续更换默认模型不覆盖已有显式选择。
- 思考模式、模型和权限控件使用相同 Field/Select 字号与灰色层级，不使用突兀黑色选中块。
- 保存失败保留选择；删除模型时由模型工作台检查引用，不能留下不可解释的悬空配置。

## Channels

- 列表只管理当前队友加入哪些频道，不在这里覆盖频道的 Ling Agent 模型或其他成员模型。
- 搜索、当前成员关系和加入/移除行动使用紧凑行；成功后的列表变化不重复显示说明。
- 频道归档、缺失或权限限制持续显示异常，不展示正常健康废话。

## Skills

```text
[搜索技能或用途] [全部技能]
技能                     说明                         使用
```

- 只显示未归档、当前可绑定的技能；来源、Skill ID、checksum、路径和技术策略不进入列表。
- 搜索匹配名称、说明和用户可见工具名称。正常技能不显示“可执行”标签，异常时仅显示“需处理”。
- Switch 即时绑定/启用、重新启用或停用并保留配置；整行打开详情。
- 详情只展示名称、说明、当前队友是否使用、异常阻断，以及默认折叠的工具/确认规则。
- 导入、归档和技能编辑属于技能库；解除绑定位于详情。空态只提供一次“前往技能库”。
- 列表自然高度，超过可用视窗后内部滚动，不设置固定大高度或永久 scrollbar gutter。

## Tools And Permissions

- 默认显示“可用能力”和“默认执行范围”，状态使用“可用 / 使用前确认 / 被限制”。
- 不展示重复技术信息、raw allow/ask/deny、required actions 或默认权限跳转按钮。
- 只有权限缺失或被工作区阻止时显示“去处理”；工作区默认设置仍由 Settings 管理。
- MCP 只在当前队友确有 Server、授权或异常时出现，并与权限摘要整合，不建立普通用户空页。
- 当前缺少队友级安全写接口时保持只读，不用 disabled Switch 伪装可编辑。

## Presentation

- 内容自然高度，超过视窗后内部滚动；不靠灰色说明填满页面。
- 队友私聊是左侧高频核心入口。进入队友的导航使用非阻塞切换，模块就绪前保留当前稳定页面；从其他页面进入队友或在
  队友之间切换时，数据继续在后台加载，但不得展示短暂的全页或消息区 Loading；请求完成前也不展示“暂无消息”假空态。
- 消息快照必须绑定工作区和队友身份。切换后的第一帧不得在新队友标题下显示旧队友消息；首次进入工作区或工作区路径
  改变时也保持稳定会话壳，仅在真正失败时显示归属于当前队友的错误状态。
- Header、表单、列表和确认 Dialog 在 Light/Dark、`1440x960`、`1280x800` 下保持相同信息层级。
