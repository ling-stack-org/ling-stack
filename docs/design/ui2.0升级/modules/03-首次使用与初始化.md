# 首次使用与初始化

Status: Web implemented; packaged Desktop restart remains a release gate

## Product Decision

首次使用采用柔性引导：首次配置未就绪时自动出现，但用户可以跳过，不锁死产品。引导只帮助建立可用
workspace 和第一个聊天模型，不复活旧 channel/task/run 向导，也不新增 `ViewId`。

## Trigger

只有 daemon、workspace 和 provider 首轮状态稳定后才能判断是否打开。以下任一情况需要引导：

- workspace 不可用；
- daemon 当前不可用；
- 没有检查通过的聊天模型。

短暂 loading、后台刷新和网络抖动不得触发 Dialog 闪现。已有可运行 workspace 与模型时保持静默。

## Persistence

`ling-first-run:v1` 是版本化客户端 UX 偏好，只保存 `skipped|completed`、可选 workspace identity 和时间，
不保存 secret 或权威业务状态。

- 跳过和完成跨页面刷新保留；localStorage 不可用时仍允许本次会话继续。
- v1 对当前产品版本全局生效，切换 workspace 不自动重复打扰。
- 未来破坏性引导变化使用新版本键，不篡改旧记录。

## Flow

1. Workspace：显示当前目录是否可用，缺失时提供现有修复或稍后处理。
2. Model：显示是否存在可运行聊天模型；缺失时导航到模型工作台，不复制配置表单。
3. Check：汇总 readiness，可重试、完成或跳过。

每步只有一个主行动。Advanced/raw error 折叠；失败停留当前步骤并保留输入。关闭、Esc 和“稍后再说”
进入同一 skip handler。

## Stepper Layout

- 正常 Desktop Dialog 宽度下，步骤图标和标签按内容宽度固定，连接线只消费标签之间的剩余空间；
  连接线不得通过固定百分比宽度挤压标签。
- 步骤标签是一个不可拆分的可读单元。中文不得逐字竖排，其他语言不得因 connector 抢占空间而形成
  狭窄的逐字符列。
- 真实可用宽度不足时切换为紧凑纵向步骤列表；每个标签本身仍保持正常横向字序，Dialog 和页面不得
  产生横向滚动。
- 步骤布局必须覆盖产品支持的全部 locale，但不为单个语言写特例或缩小点击、图标尺寸。

## Acceptance

验证自动打开、稳定加载、跳过跨刷新、已配置静默、模型工作台修复导航、Esc/焦点恢复、Light/Dark、
`1440x960`、`1280x800`，并验证中文和长标签语言的步骤文字不会被压成竖列。Desktop renderer 可复用
同一合同，但 packaged restart 仍由发布清单验收。
