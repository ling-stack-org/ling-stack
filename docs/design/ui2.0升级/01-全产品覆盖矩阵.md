# Ling UI 2.0 全产品覆盖矩阵

## Matrix Rules

- 本表登记产品级功能组；模块文档继续拆到具体按钮、字段和状态。
- `Target` 是目标共享 primitive，不代表改变业务能力。
- 初始状态均为 `inventory`。实现和真实浏览器验收后才能更新。
- Evidence 路径在实施时写入 `evidence/`，不得用代码截图替代运行页面。
- Model Workbench、Plugin Manager 与 P7C.D Desktop Theme Pack Persistence 使用扩展列分别记录当前实现、
  迁移状态和验证状态；其余尚未进入逐 Function closeout 的模块继续使用紧凑列。
- 机械汇总时，扩展行只有验证状态达到完整 `verified` 才计入 `verified`；已实现但仍为 focused、partial、
  fixture-only 或缺少平台证据的行计入 `implemented`，不得借用 Web 证据关闭 Desktop gate。
- 紧凑行的 `Status` 与扩展行的 `Verification status` 必须只使用
  `verified / implemented / designed / inventory / blocked`；测试数字、平台缺口和 partial 原因写入模块文档或
  evidence metadata，禁止在状态单元格混入自然语言。
