# 布局栅格与页面骨架

## Global Grid

- AppShell 负责全局 Sidebar、Workspace、可选 Inspector。
- Feature 页面只填充 Workspace，不重新创建主导航。
- Settings 使用全屏 Settings shell，不与主 Sidebar 同时显示。
- Desktop renderer 复用页面骨架，窗口 chrome 位于 AppShell 之外。

## Standard Widths

- Sidebar 默认 `236px`，折叠态由现有 IA 决定，不在 UI 2.0 新增路由。
- Inspector 推荐 `320-420px`，支持拖动时必须设置 min/max。
- 会话正文使用统一 conversation width token，三类会话一致。
- Dialog：small `360px`、medium `520px`、large `720px`，最大宽度不超过 viewport 减 `32px`。
- Drawer：small `320px`、medium `400px`、large `480px`，内容内部滚动。

## Page Structure

- PageHeader 高度稳定，标题和动作不得因 loading 或 badge 改变布局。
- PageToolbar 控件高度一致，搜索占剩余空间，行动区不换行。
- Split view 左侧列表设置最小宽度和滚动；右侧详情使用 `minmax(0,1fr)`。
- 表格在 1280px 下不依赖横向滚动；技术列进入 Inspector。
- Canvas、Timeline 等领域界面可全宽，但工具条仍使用共享控件。

## Scroll Ownership

每一层只能有一个主要垂直滚动责任：页面、列表或 Inspector。Dialog/Drawer 头尾固定，
body 滚动。列表超过设计边界时内部滚动，不能无限拉长 Settings。

## Empty And Loading

Skeleton 必须预留稳定尺寸。EmptyState 不改变容器高度，不使用大卡片。动态 badge、按钮
和 spinner 不得让 grid track 抖动。
