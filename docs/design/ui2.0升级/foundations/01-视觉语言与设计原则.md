# 视觉语言与设计原则

## Character

Ling 是本地优先 AI 工作空间，不是营销网站，也不是裸露内部字段的诊断控制台。视觉
应当安静、可信、紧凑、可扫描。界面通过层级和对齐帮助用户工作，而不是通过颜色和
装饰制造存在感。

## Hierarchy

默认层只回答：当前对象是什么、处于什么状态、下一步主行动是什么、是否需要处理。
同一信息不得在导航、页面标题、卡片标题和灰色说明中重复出现。

- Page title：`20px/28px`，只用于页面或当前对象。
- Section title：`14px/20px`，用于任务分区。
- Body：`13px/20px`。
- Compact/meta：`12px/18px`，只用于时间、来源和必要限制。
- 不使用负 letter-spacing，不随 viewport 连续缩放字号。

## Surfaces

- 页面背景、Sidebar、Panel、Subtle 四级足够，不增加装饰层。
- 页面 section 默认无边框；单项实体、工具框架、Dialog 才可使用边框。
- 禁止 card inside card。Inspector 内使用分隔线和 disclosure，而不是继续嵌卡片。
- 高密度列表使用行，不把每一项改为卡片。

## Color

- 中性色承担结构，语义色只承担状态。
- success 不用于普通“已配置”；warning 不用于引导注意；danger 只用于真实错误和破坏。
- 一个对象默认只显示一个主状态，不堆叠多个绿色 badge。
- 身份色仅用于头像、成员点或小型来源标记，不铺满背景。

## Copy Density

- 删除重复说明和实现术语。
- 字段帮助只解释格式、后果或修复路径。
- raw id、path、hash、transport、metadata 等进入 Details。
- 空态一句说明加一个主行动；不得用大面积空卡片撑满第一屏。

## Acceptance

- 第一眼能扫出状态和行动。
- 不依赖颜色才能理解状态。
- 1280px 宽度下标题、状态和操作不挤压。
- `ling-light` / `ling-dark` 视觉层级一致，不出现硬编码白块或灰字糊成一片。
