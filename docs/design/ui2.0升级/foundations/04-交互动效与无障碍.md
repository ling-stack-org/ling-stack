# 交互动效与无障碍

本文件同时管理键盘、焦点、动效、状态转场和 reduced-motion。组件和页面不得再建立
私有动效语言。

## Keyboard

- 所有操作可通过 Tab 到达。
- Menu、Tabs、SegmentedControl 使用方向键语义。
- Dialog 和 Drawer 锁定焦点，关闭后恢复到 trigger。
- Esc 关闭非 destructive overlay；busy destructive 流程可暂时阻止关闭。
- 禁止只通过 hover 暴露完成任务所需的操作。

## Focus

- 使用统一 focus ring：`2px` accent，offset `2px`。
- `:focus-visible` 才显示键盘 ring，不用去除 outline 后无替代。
- 输入错误同时显示 border、文案和 `aria-invalid`，不能只变红。

## Motion

- hover `120ms`，overlay open/close `180ms`，drawer resize/transition 最长 `240ms`。
- 所有时长和 easing 使用 motion tokens，禁止 raw duration 和 `transition: all`。
- 禁止摇晃、弹跳和装饰性循环动画。
- Summary、Drawer 和 Bottom Panel 的独立状态不得通过先隐藏再出现制造闪烁。
- 动画中再次点击以最后输入为准，从当前状态反向，不跳到起点或终点。
- `prefers-reduced-motion` 下取消位移和缩放，只保留必要淡入淡出。

### State Transitions

| Surface | Default | Reduced motion |
|---|---|---|
| Hover/focus color | `120ms` | 可保留 |
| Dialog/Popover/Menu | `180ms` opacity + limited translate | 仅 opacity |
| Drawer/Sidebar | 最长 `240ms`，尺寸和内容同步 | 直接切换或短淡入 |
| Toast/InlineFeedback | `180ms`，退出不得挤压正文 | 直接出现/消失 |
| Theme artwork | 资源就绪后 `180ms` crossfade | 直接替换 |

- 展开、收缩和反向点击以最新输入为准，不先完成旧动画。
- loading、success、failure 的切换不得重建父布局或导致操作位置跳动。
- 拖动只更新直接反馈；昂贵持久化在结束时提交，并保留键盘等价操作。
- 列表项不得逐行 stagger 入场，长列表和持续运行状态不得使用循环装饰动画。

## Hit Areas

- IconButton 最小 `32x32px`。
- 行内按钮不能小于 `28px` 可视高度，但点击区域仍应达到 `32px`。
- Checkbox、radio、switch 使用稳定 control cell，不被 grid 压缩。

## Screen Reader

- Icon-only 必须有 accessible label。
- 状态变化使用适当 `status` 或 `alert`，避免重复播报。
- Field label、description、error 正确关联。
- Tooltip 不是唯一说明来源；disabled 原因可通过相邻文案或可聚焦 wrapper 获取。
