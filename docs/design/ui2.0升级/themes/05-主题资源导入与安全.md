# 官方主题资源与安全

## Goal

保证 Ling 主题只是经过产品策展和工程验证的数据与应用内资源，不能变成 CSS/JavaScript 注入、路径穿越、远程跟踪、第三方 IP 或品牌替换入口。

## Current Product Boundary

Ling 不提供主题包导入能力。`.ling-theme` 归档、第三方主题包、远程主题资源、Theme Studio 生成包和包内 runtime artwork 都不是当前产品能力。

历史 local-import / local-generated 数据可以保留在本地存储中用于兼容诊断，但不能在主题列表继续展示为可用主题，也不能通过修复、重新导入或生成入口恢复成产品能力。

## Official Theme Resources

官方主题只允许以下内容：

| Resource | 当前状态 | 说明 |
|---|---|---|
| semantic tokens | allowed | 编译进 `@ling-stack/ui-react` 的完整 token set |
| Desktop tokens | allowed | 受控材质和窗口表面参数 |
| scene metadata | allowed | 只包含已注册 scene ID、角色和角落开关 |
| SceneArtwork implementation | allowed | 应用代码拥有的场景资源，不属于主题包输入 |
| Ling Core IP | allowed | 官方设计资产；轮廓、脸部和材质规则由 IP 合同固定 |
| preview thumbnail | derived | 由同一个 SceneArtwork 或色板生成，不单独接受外部文件 |

## Prohibited Theme Content

- `.css`、`.js`、`.mjs`、`.html`、`.wasm`、字体、可执行文件和脚本。
- 远程 URL、data URL、Iconfont、外部 SVG、iframe 和网络加载声明。
- 任何 selector、class name、DOM path、React component 或 Feature ID。
- Presentation Profile definition、slot 坐标、opacity/blur 原始值或未注册 Profile ID。
- Logo、favicon、LingStackLogo 替换或品牌近似资产。
- workspace 文件、用户秘密、token、API Key 或 daemon 地址。
- 第三方主题包内的背景、hero、角落装饰或视频。

## Scene Safety

- Scene ID 必须来自应用注册表。
- scene 不包含可读文字、第三方 IP、伪控件、水印或 Logo 替换。
- `mascot` 与 `corners` 只能打开/关闭应用已有元素，不能推动业务布局。
- 对比检查不通过时，提高遮罩或回退 token-only surface，不通过任意 CSS 补救。
- UI screenshot、带文字效果图和窗口 mockup 不能作为官方场景。

## User Background Safety

用户自定义背景不是 Theme Pack 资源。它走独立的偏好、验证和受管仓库：

- 静态图片：PNG、JPEG、静态 WebP，最大 16 MiB、8192 单边、1600 万像素。
- 动态壁纸：MP4、WebM，最大 64 MiB、4096 单边、120 秒。
- 拒绝 GIF、APNG、动画 WebP、SVG、远程 URL、多文件和未知格式。
- Web 保存到 IndexedDB 独立 stores；Desktop 保存到 app data 下受管 `backgrounds/` 目录。
- renderer 不能选择任意文件系统路径；Desktop main 重新验证大小、签名、摘要、路径和 revision。
- 背景资源不能读取网络、workspace、daemon、secret 或 shell。

## Persistence And Recovery

- 用户背景偏好使用 revision、requestId 和 payload digest 提交。
- 替换失败保留旧 committed；clear 是显式操作，重启或代码回退不得恢复已清除引用。
- 运行时发现资源损坏时回到当前主题默认画面，保留诊断和修复入口。
- 回退只修改外观状态，不刷新当前任务、不关闭 Dialog、不清除输入。

## Security Acceptance

- 非 built-in scene、未知 schema、非法 token、远程 URL 和可执行内容全部被拒绝。
- 主题无法改变 Logo、主导航、隐藏危险操作或覆盖 `.ling-ui-*` selector。
- 背景文件大小、签名、尺寸、时长、摘要和受管路径由对应仓库验证。
- 导入、切换、删除和回退的失败都不留下半完成注册表。
