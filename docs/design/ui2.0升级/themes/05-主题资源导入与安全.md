# 主题资源导入与安全

## Goal

允许用户导入本地主题，同时保证主题只是经过验证的数据和资源，
不能变成 CSS/JavaScript 注入、路径穿越、远程跟踪或品牌替换入口。

Codex Dream Skin 的可借鉴点是 theme manifest、图片大小/路径校验、safe area、
focus point、staging、restore 和跨平台预设。Ling 不引入其 CDP 注入、DOM selector
覆盖、大量 `!important` 或任意 CSS 能力。

## Import Format

第一阶段只支持用户显式选择的本地 `.ling-theme` 归档。

当前批准边界：

- 2026-07-21 用户确认：D1、D2 均锁定为方案 A；除非后续有新的显式产品决策，实施不得重新解释或扩大该边界。
- D1=A：导入包只接受 semantic tokens、可选 `LICENSE.txt` 和一个隔离 Preview。所有 runtime
  `artwork`、shell/background、hero 和 corner slot 一律拒绝。
- D2=A：当前持久化只完成 Web IndexedDB。Desktop 原生 repository/IPC/packaged restart 是明确待做。

```text
my-theme.ling-theme
  theme.json
  assets/preview.webp
  LICENSE.txt
```

- `.ling-theme` 是 ZIP 容器，但不接受通用 ZIP 文件扩展名作为主题。
- 根目录只能存在 manifest、license 和 `assets/`。
- 归档最大 20 MB，解压后最大 32 MB，文件数最多 16。
- `theme.json` 最大 1 MB，单张图片最大 16 MB。
- 不接受密码归档、多卷归档、symlink、hardlink 或特殊文件。

## Path Safety

- 解压前规范化所有路径，拒绝绝对路径、`..`、空路径和控制字符。
- 大小写不敏感平台上拒绝同名冲突。
- 资源必须留在当前主题目录，不允许 file URL 或 workspace 路径引用。
- Desktop staging 使用 app data 下的随机临时目录，发布前再次确认真实路径属于 staging root。
- Web 不保留用户原始绝对路径，只保存经验证资源 blob。

## Accepted Assets

| Asset | Formats | Imported package status | Purpose |
|---|---|---|---|
| Preview | PNG, JPEG, WebP | allowed | isolated ThemePicker/Preview Dialog only |
| License | UTF-8 text | allowed | attribution and redistribution information |
| Background | PNG, JPEG, WebP | blocked in imported packages | later verified Theme Studio artwork only |
| Home hero | PNG, JPEG, WebP | blocked in imported packages | later verified generated Profile only |
| Corner decoration | transparent PNG/WebP | blocked in imported packages | later verified fixed slot only |

不接受 SVG 作为导入主题资源，避免外部引用、脚本、字体和复杂过滤器风险。
内置品牌 SVG 仍由产品代码管理，不属于 Theme Pack。

## Prohibited Content

- `.css`、`.js`、`.mjs`、`.html`、`.wasm`、字体、可执行文件和脚本。
- 远程 URL、data URL、Iconfont、外部 SVG、iframe 和网络加载声明。
- 任何 selector、class name、DOM path、React component 或 Feature ID。
- Presentation Profile definition、slot 坐标、opacity/blur 原始值或未知 Profile ID。
- Logo、favicon、LingStackLogo 替换或品牌近似资产。
- workspace 文件、用户秘密、token、API Key 或 daemon 地址。

## Validation Pipeline

```text
Select local bundle
  -> inspect archive metadata without extraction
  -> enforce count and size limits
  -> extract to isolated staging
  -> validate path and file identity
  -> parse manifest with strict schema
  -> validate token allowlist and contrast
  -> reject every runtime artwork or Presentation Profile payload
  -> decode image and verify MIME/dimensions
  -> render isolated preview fixture
  -> user confirms import
  -> publish manifest, package metadata and optional Preview in one transaction
  -> update registry with rollback
```

任一步失败都不得改变当前主题、System mapping 或已安装主题目录。

## Image Rules

- Imported packages may contain only the isolated Preview image. The remaining artwork rules apply to
  later Theme Studio generated assets before they can be published.
- 解码后必须与声称 MIME 一致。
- 最长边不超过 8192px，像素总量不超过 32MP。
- 忽略 EXIF 方向以外的敏感元数据，发布存储时可重编码清理 metadata。
- `safeArea`、`focusX/focusY`、`taskMode` 和 Profile intensity 只能改变背景展示，不能推动业务布局。
- 对比检查不通过时，强制 `taskMode: off` 或拒绝导入，不通过添加任意 CSS 补救。
- UI screenshot、带文字效果图和窗口 mockup 不能作为 `shell-background` 直接安装。
- corner decoration 必须含透明通道，并通过伪控件、Logo、文字和遮挡检查。

## Generated Theme Safety

Theme Studio 生成主题使用同一资源、Schema 和发布校验，并增加：

- Quick 模式图片只在本地分析，不自动上传。
- Generate/Advanced 模式必须在模型调用前获得用户确认。
- Planner 输出只作为候选 JSON，未知字段、CSS、selector、Logo replacement 全部拒绝。
- 生图结果经过 UI/text/logo/watermark 风险检查后才能进入 Theme Compiler。
- 模型输出的颜色、Profile 和 safe area 不受信任，以 Compiler 本地分析为准。
- 生成主题 source 为 `local-generated`，不能冒充 built-in。
- AI 生成或导入成功不代表素材拥有商业、肖像或再分发权利。

## Persistence

- Web token manifest、package metadata 和 Preview Blob 保存于 IndexedDB v2，只把当前已验证主题的
  小型 bootstrap snapshot 写入 localStorage。
- Web 图片不转换成大型 localStorage data URL。
- Desktop 保存于 app data 下的 `themes/<themeId>/` 是 `DESKTOP-THEME-PACK-PERSISTENCE-001` 待做项，
  当前不得声称已经实现。
- Theme Studio 草稿保存在独立 `theme-drafts/<draftId>/` 或 Web Blob store，不能被 Registry 当作已安装主题。
- Web 安装、替换、删除使用一个 IndexedDB readwrite transaction。Desktop 后续使用同卷随机 staging +
  atomic rename，不让 watcher 看到半完成主题。
- 删除当前 fixed 主题前先切换到内置 fallback；不允许删除内置主题。

## License And Attribution

- 导入界面显示主题名、作者、来源和 license，不自动打开外部链接。
- 未声明 license 的主题可供本地使用，但显示“未声明再分发权利”。
- 人物肖像、IP、品牌和第三方素材权利由用户/主题作者负责，Ling 不将导入成功
  解释为可商用或可公开分发。
- 直接复用第三方 MIT 代码时保留版权和许可声明；主题素材单独审查。

## Failure And Recovery

- 导入失败使用 Dialog InlineFeedback，原始 parser/decoder 信息进 Details。
- 导入成功使用全局 Toast，不自动切换，除非用户勾选“导入后使用”。
- 运行时发现主题损坏时，原子回退到内置主题，保留损坏目录供用户删除或重新导入。
- 回退只修改外观状态，不刷新当前任务、不关闭 Dialog、不清除输入。

## Security Acceptance

- ZIP Slip、symlink、超限文件、伪造 MIME、非法 token、远程 URL 和未知 schema 全部被拒绝。
- 导入主题无法改变 Logo、主导航、隐藏危险操作或覆盖 `.ling-ui-*` selector。
- 无法从主题包访问网络、workspace、daemon、secret 或 shell。
- 导入、切换、删除和回退的失败都不留下半完成注册表。
- 模型取消、超时、非法 Planner JSON、生成伪 UI 和 Compiler blocker 都不能发布主题。

## Desktop Persistence TODO

`DESKTOP-THEME-PACK-PERSISTENCE-001` 保持 `inventory`，必须单独完成：

1. `appData/themes/<themeId>/` 原生 repository；
2. canonical path、同卷随机 staging、fsync（平台支持时）和 atomic rename/swap；
3. main 进程重新验证路径、大小、类型和 checksum，renderer 不能选择绝对目标路径；
4. list/read/install/reimport/delete 的 typed main/preload IPC 与可产品化错误分类；
5. 写入、rename、权限、损坏和中断后的回滚与 staging 清理；
6. 打包应用重启后的主题列表、active selection 和 first-frame 恢复；
7. macOS 与 Windows 的安装、重导入、删除、失败回退和重启证据。

Web IndexedDB、browser fixture、renderer token sync 或 PiP screenshot 均不能替代上述 Desktop 验收。
