# 官方主题包产品模型

## Goal

建立一个一键切换、可扩展到 Electron Desktop、不需要重写 Feature CSS 的官方外观模型。主题提供完整视觉氛围，但只改变产品表面，不改变产品语义。

## Implementation Status

经典 `ling-light` / `ling-dark` 已实现。`ling-breeze`、`ling-ocean`、`ling-night`、`ling-sakura`、`ling-ember` 五套官方场景主题进入设计实施；它们共享同一个 Ling Core IP。最终状态以[官方场景主题与背景验收矩阵](../../full-window-theme-background-acceptance-matrix.md)和当前验证报告为准。

## Theme Pack Is The Unit

官方主题包平级存在：

```text
ling-light
ling-dark
ling-breeze
ling-ocean
ling-night
ling-sakura
ling-ember
```

`ling-light` 和 `ling-dark` 是经典高密度工作区主题；三个 scene 主题是完整视觉场景。Family 只用于展示归组，不产生 CSS 继承、token 合并或自动配对。

## Selection Model

```ts
export type ThemeSelection =
  | { readonly mode: "fixed"; readonly themeId: string }
  | { readonly mode: "system"; readonly lightThemeId: string; readonly darkThemeId: string };
```

默认 selection：

```ts
{
  mode: "system",
  lightThemeId: "ling-light",
  darkThemeId: "ling-dark",
}
```

Fixed 表示用户选择一个具体官方主题；System 表示按系统明暗在映射主题中解析。System 不是 Theme Pack ID，也不在主题列表渲染成主题卡。

## Resolved State

```ts
export interface ResolvedThemeState {
  readonly selection: ThemeSelection;
  readonly themeId: string;
  readonly colorScheme: "light" | "dark";
  readonly source: "built-in" | "fallback";
}
```

Theme resolution 不依赖当前 ViewId、Settings section、workspace、channel 或业务状态。历史 local-import / local-generated selection 不再解析为可用主题，按颜色模式回退到官方浅色或深色主题。

## Display Rules

- 设置页分开展示“跟随系统”和“主题”。
- 关闭跟随系统时，主题列表的选中项是唯一实际主题。
- 开启跟随系统时，主题列表显示当前解析结果，但不把 `System` 渲染成主题卡。
- 场景主题显示与全窗一致的场景缩略图；经典主题显示色板。
- 主题名称、作者、来源和许可证是元数据，不能覆盖产品文案。
- 不展示导入、创建、修复、重新导入、删除或预览主题包操作。

## Allowed Visual Changes

- App、panel、elevated、subtle、pressed、sidebar、composer 等 surface。
- 文字、边框、focus、selection、scrollbar 和 accent。
- success、warning、danger、info 的语义色组。
- 阴影强度、Desktop 材质和官方 scene metadata。
- 原生 `color-scheme`、code surface 和图表语义色。
- 选择 Ling 内置、版本化且通过验收的 Presentation Profile。
- 调整 Profile 允许的 surface/artwork intensity 和固定装饰开关。

## Forbidden Visual Changes

- 控件高度、字号、行高、间距、栅格、页面宽度和响应式断点。
- Button、Dialog、Drawer、Menu、Toast 和 Composer 的结构。
- Lucide 图标映射、Logo、favicon、队友头像和内容资产。
- z-index、focus order、键盘行为、loading 范围和业务状态。
- 通过主题隐藏错误、诊断、审批、危险操作或 disabled reason。
- 上传 Profile CSS、DOM、selector、页面 JSX、任意坐标或未登记装饰槽位。
- 第三方主题包、远程主题资源、包内 CSS/JS/shader 或可执行内容。

## Scene Boundary

Scene metadata 是官方 manifest 的一部分，但 scene 实现由应用代码拥有。Theme Pack 只声明 scene ID 和固定开关，不保存 SVG、CSS、脚本、路径或坐标。

首批 scene：

- `forest-breeze`：植物、树层、小径、Breeze Ling、角落枝叶。
- `ocean-drift`：天空、云、海面、波浪、纸船、Ocean Ling。
- `midnight-aurora`：星空、极光、山层、月亮、Night Ling。
- `sakura-bloom`：花枝、石台、飘落花瓣、Sakura Ling。
- `ember-dusk`：暮色丘陵、光路、草叶、Ember Ling。

Scene 可以在 Home、Sidebar、Conversation 和 Channel 的普通工作区透出；Settings、表格、审批、诊断、media-canvas、overlay 和高密度管理页面保持清晰实底。自动化工作区虽然复用管理路由，但显式声明为环境层例外：页面壳层可见 Scene，列表正文、表格和弹层仍使用清晰实底。

## Custom Background Boundary

用户背景是独立个人偏好，不属于 Theme Pack。上传本地图片或 MP4/WebM 动态壁纸后，媒体覆盖主题默认画面；清除后回到当前主题默认场景或纯色。切换主题保留用户媒体，只重新计算遮罩和材质。

## Accessibility

- Theme Pack 必须通过正文、muted text、focus、danger 和 disabled 对比度检查。
- 语义不得只依赖颜色；Icon、文字和 ARIA 保持不变。
- 场景和用户媒体必须有可读遮罩和关闭/回退能力。
- forced-colors、reduced transparency、窄窗口或资源失败时回到清晰 token-only surface。

## Non-Goals

- 不做主题商店、远程主题市场、在线执行包或第三方主题包导入。
- 不允许主题修改导航 IA、页面 JSX 或业务能力。
- 不在本期提供高级 System 主题映射编辑器。
- 不允许模型输出直接成为 runtime CSS、Theme Pack manifest 或业务文案。
