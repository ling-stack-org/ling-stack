# 导航与数据展示

Owner: `@ling-stack/ui-react` navigation and data display
Last verified: 2026-08-03

本合同覆盖 Tabs、SegmentedControl、Badge、StatusIndicator、EmptyState、Spinner、Skeleton、DataRow、
Table 与 InspectorSection。

## Navigation

- Tabs 切换同一对象的平级页面；SegmentedControl 切换少量即时视图，不能模拟命令按钮。
- 当前项由文字、位置和状态共同表达，不只依赖颜色。
- 页面级切换、搜索和摘要位于滚动区外；列表和 Inspector 超限后各自内部滚动。

## Status

- Badge 表达短标签，StatusIndicator 表达真实运行或健康状态；正常状态默认省略。
- success、warning、danger、info 保持固定语义，Feature 不自行发明颜色。
- 草稿、阻断、异常等需要辨识时才在列表主信息旁显示状态。

## Data

- DataRow 整行负责选择或打开详情，离开当前壳层的动作使用显式按钮。
- Table 列宽按信息优先级稳定分配；名称/说明获得弹性空间，操作列固定且不被滚动条遮挡。
- InspectorSection 默认展示用户可行动信息，来源、ID、checksum、路径等技术信息按产品需要折叠或省略。
- EmptyState 只说明当前结果和一个有效下一步，不重复页面标题或功能介绍。
- Skeleton 只用于首次加载；刷新保留旧数据，Spinner 只出现在实际 busy owner。
- 列表少量内容自然高度展示，超过可用视窗后使用透明轨道的悬浮滚动条。
