## Icons

- 使用共享 Lucide 映射；同一动作跨页面使用同一图标和 accessible name。
- IconButton 默认无装饰外框，hover/focus/active 由受控背景或 focus ring 表达。
- 产品 Logo、队友头像、状态图标和命令图标是不同资产类别，主题不能替换其语义。

## Theme Picker

- “跟随系统”是解析策略，具体 Theme Pack 是选项；两者不得混成一张主题卡。
- 主题列表只展示官方内置主题；不提供导入、生成、修复、重新导入、删除或预览主题包操作。
- 场景主题显示与全窗一致的场景缩略图；经典主题显示色板；预览失败不改变当前主题。
- 切换主题保持当前页面、滚动位置、Dialog/Drawer 和业务状态。

## Theme Studio（已停用）

当前产品只提供官方内置主题。Theme Studio / Quick / Generate / Advanced 不再是产品入口；本节仅作为历史实现参考，不能作为当前开发依据。
