## Icons

- 使用共享 Lucide 映射；同一动作跨页面使用同一图标和 accessible name。
- IconButton 默认无装饰外框，hover/focus/active 由受控背景或 focus ring 表达。
- 产品 Logo、队友头像、状态图标和命令图标是不同资产类别，主题不能替换其语义。

## Theme Picker

- “跟随系统”是解析策略，具体 Theme Pack 是选项；两者不得混成一张主题卡。
- 内置、导入和生成主题使用同一列表语法，仅来源、删除能力和修复状态不同。
- 预览显示经验证 token 和允许的 artwork；预览失败不改变当前主题。
- 切换主题保持当前页面、滚动位置、Dialog/Drawer 和业务状态。

## Theme Studio

- Quick：图片只参与本地配色和 token 生成，不发布运行时背景，不要求模型或网络。
- Generate：模型生成纯 artwork candidate，用户确认后交给 Compiler。
- Advanced：结构化 Planner 与 artwork 能力生成候选，不直接输出 CSS、manifest 或业务文案。
- 上传、生成、检查和安装是独立状态；失败保留可重试输入，安装成功后才更新 ThemePicker。
- 任何图片都不得包含伪控件、可读指令、Logo、签名或水印；来源与许可必须可追溯。
