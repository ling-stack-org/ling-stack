本合同覆盖 Dialog、Drawer、Popover、Tooltip、Menu、Toast 与 InlineFeedback。

## Overlay

- Dialog 处理阻断式确认或短流程；Drawer 处理可随列表选择切换的详情；Popover/Menu 处理锚定选项。
- 同一用户动作只打开一个主要 overlay。关闭恢复 trigger 焦点，Esc 关闭非 destructive surface。
- Portal 使用共享层级和 collision detection；内容超过视窗时 body 内部滚动，header/footer 固定。
- destructive busy 期间可以阻止关闭，但必须显示进度和失败恢复；禁止浏览器 `confirm()`。
- Tooltip 只补充图标或缩略信息，不承载完成任务所需的唯一说明。

## Feedback

- Toast 用于短暂、跨局部但无需停留的结果；成功使用共享默认 3 秒自动消失，悬停/焦点时按共享规则暂停。背景保存与恢复默认等设置操作复用唯一全局 Toast 和稳定 scope 去重，不能在 Feature 内另建常驻成功状态或反馈计时器。
- InlineFeedback 属于具体对象、字段或操作，失败和阻断持续到解决或重试。
- 正常健康状态不常驻提示；警告、审批、阻断和需要用户行动的状态持续可见。
- raw error、request ID、provider payload 和路径进入折叠技术详情，不进入默认提示。
- 同一 action owner 使用稳定 key 去重；旧请求不得覆盖新请求结果。

## Accessibility

Dialog/Drawer 锁定焦点，Menu 使用方向键，Toast/反馈使用适当 `status` 或 `alert`，避免同一状态重复播报。
