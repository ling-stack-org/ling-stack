# 基础控件与表单

Status: active UI2 component contract
Owner: `@ling-stack/ui-react` controls
Last verified: 2026-08-03
Code anchors: `packages/ui-react/src/controls/`, `packages/ui-react/src/styles/controls/`
Test anchors: `packages/ui-react/test/primitives.test.mjs`, `apps/web/e2e/ui2-form-controls.spec.ts`

本合同覆盖 Button、IconButton、Input、Textarea、Select、Field、Checkbox、Radio、Switch 和
数值控件。具体 TypeScript API 由 `@ling-stack/ui-react` 类型与测试负责，文档只保留跨页面语义。

## Commands

- Button 只表达明确命令；主次、危险、静默和文字按钮使用统一 variant。
- 熟悉的单一动作优先 IconButton，并提供 Tooltip 与 accessible label；图标按钮不增加装饰外框。
- loading 自动阻止重复提交，但保留原宽度和标签；busy 范围只覆盖发起动作的控件。
- disabled 原因必须可获得，不能只降低透明度。
- 默认命中区域不小于 `32x32px`，主要命令可使用 `36px` 或 `40px` 高度。

## Fields

- Field 统一拥有 label、description、error、required 和 control 关联；可省略无价值灰色说明。
- Input/Select 不泄漏 raw ID；选项显示用户可理解的名称和必要辅助文案。
- Textarea 可增长但受页面最大高度约束；长内容在控件内部滚动，不推走固定 footer。
- Checkbox/Radio/Switch 使用稳定 control cell。二元设置用 Switch/Checkbox，互斥少量选项用
  SegmentedControl，长选项集用 Select。
- 错误同时使用文案、边框和 `aria-invalid`，保存失败不得清空用户输入。

## Ownership

Feature 只组合控件、提供领域数据和校验，不命中 `.ling-ui-*` 内部 class，不复制 focus、disabled、
loading 或 portal 行为。
