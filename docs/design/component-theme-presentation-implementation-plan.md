1. **I0 设计与留档**：保留既存源码、资产与文档差异；更新本合同与实施方案。首轮截图只作对照，不能作为第二轮验收。

3. **I2 内容与浮层**：消息/引用/代码标题、卡片/表格、Menu/Dialog/Toast、Badge/EmptyState 的共享材质与层次；保持状态色与阅读保护。

5. **I4 交付**：人工检查相同内容下三主题的有/无背景截图，修正不协调处；记录源码哈希、实际测试与未验收边界。本轮不提交、不推送、不修改模型/用户数据、不启用空数据库服务。

### 运行时验收边界

浏览器比较同主题首页/普通/频道/私聊的 computed style；三套设计参数须明确不同。覆盖 Ocean→Night→Journey→Light/Dark 切换，真实组件的按钮、菜单、Dialog、消息/引用/代码、错误与禁用/加载状态。背景单测覆盖基准、无效输入和保护下限；沿用已有媒体和播放回归。
