# 媒体生产画布优先布局

状态：active design contract

日期：2026-07-14

相关文档：

- [媒体生产体验收口](media-production-experience-refinement.md)
- [模型工作台视频生产台](model-workbench-video-production-studio.md)
- [媒体生产画布优先体验优化](media-production-canvas-priority-refinement.md)（覆盖默认右检查器、MiniMap 阈值和零场景批量动作规则）

## 1. 决策

媒体生产是分镜创作面，不是三栏表单页。页面导航已经标识“媒体生产”，因此不再保留额外的 H1、说明文案或右上角手动刷新按钮。生产台以画布为默认焦点；项目、场景序列和场景属性通过可关闭的浮动 dock 进入。

```text
左侧项目与分镜 dock  <--- 覆盖 --->  全尺寸分镜画布  <--- 覆盖 --->  右侧场景检查器
                 顶部轻工具栏：项目上下文 | 生产台 / 生成任务 | 批量生成
```

这个模式来自三类已验证的开放实现：ComfyUI 的浮动/连接式侧栏与画布上、下悬浮工具栏；InvokeAI 将项目操作放在画布工具栏与上下文菜单；Flowise 将低频节点信息按需打开而不是永久占用画布。Ling 不复制它们的复杂工作流功能，只采用“画布不让位、细节按需出现”的交互原则。

## 2. 问题

当前 `项目/分镜 | 画布 | 场景检查器` 固定三栏在 1440px 视口下持续占走约 628px 宽度；加上主侧边栏，画布只能成为中间的剩余区域。问题具体表现为：

- 标题、页面说明、tabs、项目栏和检查器同时可见，首屏没有明确主次；
- 项目选择、名称和默认模型总是占据左栏，即使用户正在安排分镜；
- 未选中场景时右栏仍占一整列，只显示说明文案；
- 两个场景被 `fitView` 放大，背景点阵、缩放控件和卡片边框共同放大噪音；
- “新建项目”和刷新与创作动作分离，且额外占据顶部命令位。

## 3. 范围与硬边界

### 包含

- 生产台画布外壳、浮动 dock、顶部轻工具栏、场景卡片密度与画布控件；
- 项目切换、新建项目、项目设置、场景顺序、场景编辑、单场景生成和按顺序生成的入口重排；
- 桌面 Web 的 1440x1000 与 1280x800 验收。

### 不包含

- 视频模型、Provider、adapter、Media Job、artifact、scene run、任务状态或审批语义改动；
- daemon route、API payload、SQLite schema 变更；
- 时间线、剪辑、拼接、字幕、配音、FFmpeg 或第三方工作流；
- 移动端专项。

若实现需要改动以上任何运行语义，停止并重新设计。

## 4. 信息架构

### 4.1 无页面级标题

`媒体生产` 由主导航表达。生产台中不展示 H1、描述、页面级 tabs 或刷新按钮。生成任务仍在同一个页面层级中，但通过紧凑切换器进入，不出现第二个“媒体生产”标题。

### 4.2 顶部轻工具栏

工具栏悬浮在画布顶部中央，最大宽度不超过内容所需宽度，包含：

1. 当前项目名称与场景数；点击“项目与分镜”打开左 dock；
2. `生产台 / 生成任务` 分段切换；
3. 仅在生产台出现的 `按顺序生成` 主动作；无可运行场景时仍可打开检查面板，明确说明原因，但不允许提交。

它不包含刷新、新建项目、项目名称输入、模型选择或技术字段。工具栏不随左/右 dock 展开而重新排版，也不遮挡节点的默认安全区域。

### 4.3 左侧项目与分镜 dock

左边默认是 44-48px 的图标轨，点击后展开 288px 左浮层，覆盖画布而不压缩画布。

- rail 按钮有“项目与分镜”明确 tooltip 和 aria label；
- dock 顶部是项目选择和“新建项目”图标按钮；
- 项目重命名、默认视频模型留在现有“项目设置” disclosure；
- 场景列表是主要内容，按顺序显示，保留选择、添加、上移和下移；
- 点击场景会选中节点并自动打开右侧检查器；
- 点击 rail、dock 关闭按钮、画布空白处或 Esc 可关闭 dock；关闭状态可用 localStorage 在同一浏览器中记忆。

新建项目只在这个 dock 内出现，避免与画布创作命令竞争。

### 4.4 右侧场景检查器

未选中场景时右侧仅保留 44-48px 的“场景检查器”图标轨；不再显示永久空白栏。

- 选中任何场景会打开 360px 检查器浮层；
- X、Esc、检查器 rail 都可关闭；
- 检查器覆盖画布，画布尺寸不变化；
- 保留现有顺序：场景名称、画面提示、模型/比例/时长、当前结果、运行历史、生成按钮；
- 生成成功后的播放器保持在检查器内；画布卡片同时提供轻量预览图标，关闭检查器不影响预览、选择或运行状态。

### 4.5 分镜画布

- 画布获得页面内容区的完整宽高，dock 以 overlay 呈现；
- 默认将场景作为有序分镜，而不是通用流程节点：节点紧凑、视觉重心放在编号、标题、提示摘要、状态、可用视频首帧；
- 未选择结果时不显示无意义媒体占位；有当前结果时可显示安全的 artifact 缩略图；
- 有当前结果时显示独立预览按钮；按钮不嵌套在场景主按钮内，点击不选择节点、不移动画布、不触发生成；
- 画布首次 `fitView` 最大缩放为 1，禁止两个节点被放大成巨型卡片；
- 切换项目时重新执行 `fitView`；点击左侧场景、创建场景或复制场景后，画布保留当前缩放比例并平滑移动到左右 dock 之间的安全可见区域；重复点击已选场景也必须重新定位；
- 背景点阵降低对比度；画布控制只保留适配视图和缩放，至少两个场景时显示；缩略地图也从两个场景开始显示，帮助用户在小型分镜中快速定位；
- 只要存在场景就显示缩放与适配视图控件，控件不得被左 dock 遮挡；缩略地图使用半透明视口遮罩，所有场景节点在当前视口外仍可辨认，并在右检查器展开时自动避让；
- “位置不影响顺序”提示只在至少两个场景时显示，并保持低权重。

## 5. 命令层级

| 情境 | 唯一主动作 | 次级动作 |
| --- | --- | --- |
| 空项目 | 添加第一个场景 | 打开项目与分镜 |
| 未生成场景 | 生成此场景 | 复制、删除 |
| 已生成场景 | 重新生成 | 预览、复制、删除、切换当前结果 |
| 多个可运行场景 | 按顺序生成 | 调整场景顺序 |
| 生成任务 | 创建生成任务 | 筛选、查看详情、重试 |

没有可运行场景时，批量生成仍可打开确认面板，列出每个待完善场景的原因；实际提交按钮保持禁用，不伪造可执行状态。手动刷新从默认层移除，项目初始化、场景/运行变更和生成中的有限轮询仍通过既有 domain refresh 机制更新数据。

## 6. 交互与可访问性

- 所有 rail、dock、生成、复制、删除、排序、适配视图按钮都提供 aria label 和 tooltip；
- Esc 优先关闭最上层 dialog，其次右检查器，再次左 dock；不取消正在运行的生成；
- dock 使用 `role=complementary`、检查器使用 `role=region`，不会破坏 React Flow 的画布键盘操作；dock 以 180-220ms 淡入横移显示，关闭时保留同样的退出过渡，并尊重系统的“减少动态效果”偏好；
- 弹层的打开/关闭不改变节点位置、`sortOrder`、模型或未保存输入；
- 新建场景后选中场景、打开检查器并将焦点送到场景名称；
- 保存成功沿用全局 2 秒 toast，失败持续显示；禁止 toast 覆盖轻工具栏。

## 7. 模块边界

| 模块 | 责任 |
| --- | --- |
| `MediaProductionWorkspace` | 视图切换、dock 开关、预览弹窗状态、顶层装配 |
| `MediaProductionCanvasToolbar` | 轻工具栏与 view switcher |
| `MediaProductionDockRail` | 左/右 dock 打开关闭控制 |
| `ProjectSceneOutline` | 展开后的项目/场景内容，不管理 dock state |
| `SceneInspector` | 展开后的场景检查器，提供关闭回调 |
| `StoryboardCanvas` | 节点、边、画布 viewport、预览意图回调与低权重控制，不直接访问 API |
| `use-media-production-controller` | 保持现有请求与副作用，不引入布局逻辑 |

所有新文件与改动文件保持低于 800 行。不能把 API、Provider credential 或 artifact 原始响应传入画布节点。

## 8. 验收

- 1440x1000、1280x800：画布是最大连续区域，左/右 dock 展开不会改变画布 DOM 的宽高；
- 没有“媒体生产”大标题、页面说明、刷新和顶部新建项目按钮；
- 新建项目只在左 dock；选中场景才显示右检查器；
- 左/右 dock 可通过 rail、关闭按钮和 Esc 展开/收起；
- 两个及以上场景显示缩略地图，且卡片不过度放大；
- 缩略地图能显示所有场景节点和当前视口范围；点击左侧场景后目标卡片进入可见区域，缩放控件在左右 dock 展开时仍可操作；
- 空项目、缺模型、待完善、生成中、失败、已完成和删除确认仍有明确下一步；
- 首次成功显示“已生成”；重新生成中仍能预览旧结果，失败后保留当前结果并显示最近问题；
- 用户点击预览后，弹窗显示当前选用视频并静音自动播放，保留 controls 和完整关闭方式；切换历史当前结果后预览随之更新；
- 视频预览、场景排序、批量确认、取消、选用结果与生成任务页不回退；
- 通过 Web typecheck、i18n、媒体/模型工作台 Playwright、`git diff --check` 与真实浏览器截图。
