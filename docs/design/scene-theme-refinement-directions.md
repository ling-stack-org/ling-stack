## 目标与现状

Breeze、Ocean、Night 原有简易 SVG 场景目前已替换为完整图片，并同步调整语义配色和共享材质。目标保留“两浅一深”的结构，分别覆盖清新森林、海边开阔和山谷机甲三种工作氛围。Breeze 按用户 WorkBuddy 参考改为天空森林插画；Night 改为用户确认的山谷机甲游戏美术，Ocean 已改为现成的夏日漫画插画，不再沿用“三套全实拍”的方向。

采用方向为 **Breeze · 森灵晴空、Ocean · 夏日海风、Night · 山谷眺望**。继续使用既有 theme ID，保留偏好与选择记录；产品主题名称仍为 Ling Breeze / Ocean / Night。

## Breeze 自研背景替换（2026-10-29）

原 Breeze 背景来自用户提供的森林插画，作者与公开分发许可始终未能确认，不适合长期作为开源仓库自带资源。本轮用内置图像生成工具自研一张同气质新图：左上白桦树干与拱形叶枝入画、左上天空一小群白鸟、中央约 60–70% 保持极淡薄雾天空作为正文与 Composer 的留白、中景分层针叶林与远山薄雾、底边白雏菊/三叶草/蓝色小花的花草甸带、右侧逆光草坡与一条淡土路。

导出 `forest-clearing-v1.webp`（1672×941，317870 bytes，质量 92，原生像素不放大）与 640×360 同源缩略图（51878 bytes）。无人物、无文字、无水印、无签名。生成工具、完整提示词、负面约束与哈希见 [v7 清单](../../apps/web/public/themes/scene-themes-v7.sources.json)。新图属于本项目原创生成资产，随主题代码以仓库许可分发。

UI 从偏黄橄榄改成浅天空蓝底、鼠尾草侧栏、奶白 Composer、柔绿选中态与深绿控件。Composer 20px、导航 10px、快捷入口 20px、控件 10px、卡片/菜单 14px、Dialog 20px；消息、引用、代码标题、表头和浮层使用同一浅绿层次，不加竖条、四角线或底线装饰。语义 manifest 与官方 CSS 同步，继续由共享组件消费。合同、B0–B4 实施与验证分别见[组件合同](component-theme-presentation.md)、[实施方案](component-theme-presentation-implementation-plan.md)、[验证记录](component-theme-presentation-validation.md)。

保留 `ling-breeze` / `forest-breeze` / profile、每主题偏好和用户媒体优先级，不改模型、数据库、服务、Logo、布局与其余主题。原实拍图、被否决的 StockCake 图及 v2–v5 清单保留作历史来源。背景按用户指定落实，配套 UI 仍按实际页面复核，自动测试不代表整体美术定稿。

## 必须同步细化的 UI

每套以同一组界面完成设计，沿用既有布局与交互：

1. **首页与 Shell**：背景构图、侧栏/顶栏/rail 材质、原 Logo 可读性、首页标题与快捷入口。
2. **输入框与主操作**：输入面板、工具栏、发送按钮、选中/hover/focus/disabled 状态。
3. **三类会话**：普通会话、频道、队友私聊的正文实底、用户消息、代码、引用、表格与提示；布局层透明，工作页背景继续自动减弱。
4. **管理页面**：插件行、自动化、模型工作台、队友列表的内容层级与空白区域。
5. **设置和弹层**：设置实底、主题卡、Menu/Popover/Dialog/Toast、错误与成功状态、键盘焦点。

自然绿、珊瑚与琥珀主色不能替代业务状态的语义。尤其 Breeze 中的成功态、Night 中的警告态，需要同时通过图标、文案、边框和语义色区分。正文目标对比度至少 4.5:1，有意义的图标和焦点至少 3:1；拟定颜色经检查后才能定为正式 token。

## 共用边界

- 保留原项目 Logo；场景不要求放入新的品牌 IP。若加入人物、动物或小船，须融入整张背景的光影与尺度。
- 首轮先把静态画面与 UI 材质定稿。后续若增加动态版本，复用已完成的共享播放、减少动态效果、暂停和静态回退策略。
- 内容布局、字体系统、控件尺寸与操作方式沿用当前产品；主题差异主要由背景、语义色、材质、边界和阴影表达。
- 原有全局自定义媒体及每主题 opacity/focus/paused 数据继续生效。设计稿的官方背景展示在隔离预览中进行，避免用户现有花卉 MP4 遮住候选画面，也不清除当前用户媒体。
- 远行问剑、Ling Dark、Ling Light 作为回归基线；本提案尚未改变它们的已验收实现。

### 实测补充：主题语义 token 收敛

2026-10-28 已完成旧样式变量收敛：Web 与会话组件直接消费 `--ling-*` 语义 token，删除 `base.css` 中的旧别名映射、空的 `ling.legacy` layer 和独立的全局兼容样式入口。主题切换只改变主题 manifest 提供的 token 值，页面组件不再依赖旧变量或深色专用兜底选择器。浏览器检查直接读取活动主题的语义 token，并覆盖频道、队友私聊、普通会话及工作台表面。
