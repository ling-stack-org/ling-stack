# 对话独立绘图板

状态：已实现。视觉方向：用户选择的方案二（悬浮工具条、实色画布、底部色板）。

## 入口与行为

普通对话、频道、队友私聊的输入区提供绘图入口，打开当前对话内的独立画板；画板不是图片编辑器。完成后生成 PNG 并交给各自已有的附件上传和发送流程，由用户自行发送消息。取消不上传、不发送；空画板不能提交。

画板支持选择并拖动对象、画笔、文字、矩形和椭圆、整对象擦除、撤销/重做、颜色和笔触粗细。选择和擦除按可见笔迹或图形轮廓命中，文字按文字范围命中；擦除会移除整个对象。画布为 960 × 960 像素、深色不透明纯色，不增加网格或装饰线，生成图片与可见内容一致。弹层尺寸随可用窗口收缩；点击遮罩不会关闭画板，取消或 Escape 会放弃草稿。切换会话或关闭弹层不得向其他会话附加结果。

## 交付与验收

以共享 React 组件管理绘图与绘制状态，各会话输入区复用组件并调用原附件控制器；画板不直接请求后台。覆盖画笔、形状、文字、选择移动、擦除、历史、取消、图片生成与附件传递；运行 Web 类型检查、针对性浏览器交互和截图，验证纯色主题下的实际显示。设计图是视觉参考，不引入其中未批准的附加功能。
