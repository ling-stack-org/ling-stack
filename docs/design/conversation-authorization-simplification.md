# 会话授权入口简化

## 产品契约

普通对话、频道和队友私聊的输入区只提供一个审批入口，选择请求审批、帮我审批或完全访问；不展示独立的“工作区写入”按钮或权限预设菜单。选择完全访问须经当前会话确认，取消不改变授权；离开完全访问恢复此前受限访问范围。运行期间权限控制锁定。

设置中的高级沙箱配置负责文件访问边界，审批入口不改变受限沙箱的范围。设置可选择只读或完全访问，并可重置为默认受限沙箱；默认沙箱的说明须明确项目目录内可修改、命令仍需审批。完全访问不得绕过系统权限、Host 拒绝规则或独立审批。当前项目目录内的受限写入是执行策略，不作为独立预设选项。已保存数据不要求迁移兼容，但运行时仍须维持现行安全边界和明确的完全访问确认。

## 实施与验收

1. 统一三种输入区的授权入口，移除多余预设菜单及相关无效回调。
2. 复核设置、权限摘要、无障碍名称与提示，确保不向用户显示“工作区写入”选项；高级设置继续提供必要的文件访问控制。
3. 覆盖三种会话的入口数量、审批切换、取消和确认完全访问、退出完全访问后的权限范围及请求内容；检查设置和权限摘要。
4. 在内置浏览器实测普通对话与设置，验证无多余入口并检查控制台；执行 Web 类型、lint 和针对性回归。
