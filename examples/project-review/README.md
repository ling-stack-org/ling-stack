# Team Notes: sample project brief

This is fictional, public sample content for a small document-review task.

## Goal

Give a small team one place to keep action items after a meeting.

## First version

- Create an action item with a title, owner, and due date.
- Show open and completed items in a browser.
- Let a team member mark an item complete.
- Export the current list so it can be shared outside the app.
- Start without account registration.

## Acceptance draft

- A new item appears in the list after it is saved.
- Completing an item updates its appearance.
- Export produces a file containing the current items.

## Review request

Identify missing requirements and acceptance checks. Keep the first version small.
Separate decisions needed before implementation from improvements that can wait.
Do not implement the app or change files during this review.
